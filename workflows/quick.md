# 快速出一版

适用：用户说直接做、先出一版或无人值守。执行 [new](new.md) 的制作和检查；由执行者依据原文作常规决定并记入 brief。只有无法合理推断且会实质改变结果的缺失事实才询问，不把未答复视为授权。

试作选三页能暴露风险的真实关键页（开场、密集页、最难页），一次成型、不要求凑三版；但要先写 `style-lock.md`（见 [风格锁定](../templates/style-lock.md)），把字号档位、网格、颜色角色和"不做什么"记下来，再铺全册。数值只用 `design.css` 的字阶与基线，`book.css` 只做页面几何与克制的品牌适配；`validate` 会检查 `style.*`，越阶字号与节奏 token 覆写都是硬项。默认沿用 [Folio 的共享底座](../references/swiss.md)：先定对齐、主次比例和 bold / light 排印，再组合所需布局；不用整页演示模板代替内容判断。缺少照片可做纯文字构图；不得发明事实或把占位交成正式品。快速路线同样执行 [视觉审改](visual-review.md)、全部语言技术验收与导出实测。

交付时简述替用户决定的用途、视觉方向和规格；未完成验收只能交带水印草稿，并注明卡点。
