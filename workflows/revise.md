# 修改与接续

先读项目的 brief → experience → page-plan → 当前 `.build/latest.json` 与 `.qa/<构建ID>/`。核对本轮用户要求、当前作者源和 PDF；不要假设旧技术/视觉验收仍有效。

1. 保存可回退的基线；把已授权修改记入 brief，定位到内容 ID、页面 ID 或共用 CSS。
2. 明确影响范围。改内容分组查同类信息，改系列样式查全部成员与续页，字体/家族/纸张/页序变化查全册；保留无关已认可页。
3. 直接改作者源、译文或资源。空间不足先改分组、栏宽、分页；可续排长文用 `paginate` 并看 diff。事实和冻结内容不为容纳而改写。
4. 跑 `check`；定位语言时可暂用 `--lang`，交付前覆盖所有语言。执行 [视觉审改](visual-review.md)，记录新结论再导出，更新 experience。

| 症状 | 接续位置 |
|---|---|
| 提取为空、原稿顺序不对 | 对照原文件；扫描件先 OCR，Office 阅读顺序人工核实 |
| 字体缺失、回退、Type 3 | 字体在 project.json 声明；准备静态文件/补字库后重建，不回退系统字体 |
| 溢出、裁切、遮挡、字号或对比度失败 | `.qa/<构建ID>/<语言>/measure.md` 对应页面与目标；改作者 CSS/分组/分页 |
| MISSING / ORDER / EXTRA | `coverage.json` 对照原稿及授权，别改源材料来消告警 |
| 缺素材来源/许可 | `sources/assets.json` 核真实来源，未确认不填虚假授权 |
| 多语言长度不适配 | 修改该语言 CSS 或按 data-flow 重新续排，共用一份作者源 |
| verify 无效、拒绝正式导出 | 对当前源重新 check、实际审稿、review；看诊断而非复用旧记录 |
| Folio 冲突/未写回 | [edit-online](edit-online.md)；核旧值与当前源，不覆盖猜测 |

只给修改建议不算完成：应落实到源文件，复核新 PDF 并交付最新产物。
