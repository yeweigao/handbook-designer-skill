# 沿用系列

1. 读旧项目 brief、page-plan、作者源、家族版本与 experience，确认用户要沿用哪些品牌、结构及功能。创建独立修订目录或用版本控制保存基线，复制作者源和资源，不带旧 `.build/.qa/out` 充当新验收。
2. 继承项目的 `design.css`、实际字体、配色与系列语言；不因仓库家族升级而自动换样。结构可以延续，也可以因新材料调整，不强求创新。
3. 新原稿用 `extract.py` 放入本期 `sources/`，更新文案与译文。沿用同一语义位置的稳定 ID，新增内容给新 ID，避免旧图、旧数字、旧版权说明混入本期。
4. 按 [adaptation](../references/adaptation.md) 核整组日程、名单和续页；加删页后核目录、页码、跨页左右与装订。沿用照片确认内容仍相关、授权覆盖本期。
5. 新版从 `check` 开始重新验收；执行 [visual-review](visual-review.md)。比较的是实际 PDF 阅读效果与系列一致性，不把旧验收复制过来。

旧册仅有 PDF 时先保留原稿作为视觉与内容参照，按 [new](new.md) 重建原生作者源；没有旧格式兼容或自动还原承诺。
