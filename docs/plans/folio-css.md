# Folio CSS：统一的出版排版系统

2026-10-22 · S7 扩展。用户将原先「家族 CSS」明确扩展为原子规则、布局与组件展示，并指定与 Folio 编辑器统一品牌。

## 决定

使用一个 **Folio CSS**。Campus 是历史方案名；摄影不是另一个家族。文字、数据和摄影共享颜色角色、字体角色、网格、空间与印刷边界；图片另外使用比例、裁切焦点、出血、组图和跨页能力。Folio CSS 与 Folio 编辑器共用品牌，二者仍可独立使用。

源文件分层，使用者得到一份普通 CSS：

```text
folio/tokens.css       视觉决定：色彩、字号、字重、节奏、边距
core/base.css         有作用域的基础排印、页面版心
core/layouts.css      可选的结构组合，继承颜色与排印
core/atoms.css        单一职责的工具，可覆盖布局默认值
         ↓ Python 标准库直接拼接
folio/design.css      单文件分发，随项目复制并冻结哈希
         ↓
HTML 组件配方 → 作者页面 → 最终 PDF 审稿
```

**无需安装 Tailwind、CSS 编译器或新增 npm 包。** 借鉴其可组合方式，用稳定的 `.fl-*` 工具和 `--fl-*` 变量表达规则。CSS 文件可直接引用；打印生产继续沿用已有运行时与质量检查。

布局是可选工具，例如 4+2 正文旁栏、错位组图、共享坐标的跨页照片；组件是布局与原子的 HTML 配方，公开源码，没有另藏一层组件样式。完整页面允许作者自己的 `book.css`。这项用户要求修正早期计划「共享层不收纳布局」的过窄限制；渲染器仍不注册版式枚举。

## 约束与取舍

- 通用网格与摄影结构放在同一系统，减少两套实现的漂移；默认视觉仍需要具体的色彩、排印判断，不承诺一套 token 适合所有品牌。
- 选择有限且有名字的级数；特殊尺寸仍可写原生 CSS。不会生成所有像素值、动态解析类名或自动缩字。
- 版心与网格分开。`.fl-area` 消费运行时纸张与安全区变量；`.fl-grid` 决定内部排列。浏览器窗口不改变打印书页内部结构。
- 字体只声明实际提供的字重，不合成粗体/斜体。语义字号不替代 `data-role` 的可读性验证。
- 明暗背景重绑文字角色，嵌套浅底可恢复浅色面角色；图上文字仍须实际审稿，渐变遮罩不等于已验证对比度。
- 跨页图共享同一图像尺寸、裁切与焦点；右页按成品宽度偏移，出血不会造成图像中缝重复。要求偶数左页、奇数右页配对。
- 颜色、线条、底面都是可选原子。引用、说明和段落不自动带竖边、卡片底色或装饰线。
- 原有 Campus 文件及已交付项目不被更新覆盖；新项目显式 `init folio`。未来改 token 时递增版本，并由作者决定何时迁移。

## 展示与验证

[展示入口](../../dev/folio-css/index.html) 同时提供规则、网格、布局、组件源码与完整样册。布局可切换结构视图；规则演示直接使用分发 CSS，原始 JSON 与展示脚本由同一构建命令同步。

验证包括生成文件一致性、实际浏览器中嵌套颜色/字号、网格跨度、图片焦点、跨页坐标，以及真实样册的 PDF 技术检查和逐页视觉复核。网页展示不是印刷验收；作者复核也不计为 S12 独立评测。

参考来自用户提供的 `ppt-master-themes/website/public/layouts/index.html` 与旧 `dev/samples/themes/photo/book.html`：采纳结构/成品双视图、网格分解、摄影节奏与可解释组合；不继承旧引擎接口或逐页复制旧装饰。
