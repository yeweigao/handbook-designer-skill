03K_CONTENT_MARGINALIA · ANCHORED MARGINALIA
锚定旁注：​让每条批注与它所解释的段落同行锁定

在 CSS Grid 中，每一组「4 轨正文 + 2 轨旁注」构成独立行组，无论哪一侧文字更长，下一段都自动从较高者下方开始。

为什么传统绝对定位会让旁注漂移？

在固定坐标的模板里，一旦正文因为翻译成英文或增删句子而变长，原本对齐第二段的旁注就会滞留在第一段末尾，造成图文释义错位。

GRID 行组锁定

采用 .cn-ed-grid 同行配对后，主文与旁注共享行高，彻底根治长文旁注漂移问题。

解释贴着原文走，读者就不必在正文与页尾注释之间来回寻找。

在长文阅读页（READING）中，四轨正文直接从版心顶部起笔，两轨侧记稍后进入视线。

在线编辑器修改系列篇名时，首页与所有续页自动同步更新。

为什么长文阅读页要把标题放到左侧两轨，而让正文从第三轨顶部直接开始？因为当读者进入连续阅读状态时，最需要的是稳定、连贯的视线落点。四轨宽度的正文栏（约 26 个汉字/行）从页顶一路顺畅铺展到底部，不被巨大的页头横幅切断。

左侧两轨则像书页宽阔的外切口边注：上半部安放篇名与章节序号，下半部安放与当前段落呼应的阅读提示或观察问题。这种 2+4 结构既保留了充足的呼吸留白，又让每一页能容纳完整的三个大段落。
