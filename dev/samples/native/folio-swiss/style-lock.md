# 风格锁定 · Folio Swiss 完整样刊

这份样刊本身是"三页小样"的放大版：它先锁定骨架，再把 91 个目录项铺成 100 页。

## 一、骨架来自哪里

| 项 | 取值 | 出自 |
|---|---|---|
| 家族与版本 | folio 2.2.0 | `project.json.family` |
| 字阶（用到的档位） | 280 / 196 / 112 / 64 / 46 / 32 / 24 / 20 / 16 / 14 / 13 / 11 | `design.css` 的 `--fl-size-*` |
| 行距与基线 | body 1.75、reading 1.5、display 1.12、hero 1.0；28px 基线 | `design.css` |
| 网格 | 6 轨 / 12 轨，栏距 6mm | `design.css` 的 `.fl-grid` |
| 排印模式 | 章节扉页 bold（Noto Serif SC），目录与图版页 light（Noto Sans SC） | `.fl-type-bold / -light` |
| 颜色角色 | 纸白 #FFFFFF、软纸 #F2F0EB、墨黑 #111111、强调 #C83024、深色面 #141414 | `tokens.css`，本册未改 |
| 图片处理 | 满版出血、局部外侧出血、3:2 与 2:3 图框、图注在图外 | `references/images.md` |

## 二、非必要不新增

- 图版页的正文字号不手写，出现在 `book.css` 里的只有样刊框本身（`specimen-*` 13 个类），
  它们负责页头/示例/说明/页脚的固定关系，不承担排印与颜色。
- 没有任何 `--fl-size-*`、`--fl-space-*`、`--fl-leading-*` 覆写：字阶与节奏全部来自 `design.css`。
- 变奏章的放大字取字阶顶格的整数倍（560 = 2 × 280），只用于重复装饰，另有可读副本。

## 三、三页小样（本样刊的等价做法）

| 页 | 选它的原因 | 定下来的事 |
|---|---|---|
| 封面（p1） | 决定语调 | cover 用 light 排印、colossal 标题、底部压一段说明 |
| 正文密集页（p83 悬挂列表 / p64 纵向 timeline） | 最容易被挤坏 | 说明块固定在页脚上方，示例在剩余空间里居中，不缩字 |
| 最难页（p94 裁字 / p100 色面出血） | 最容易被误判 | 巨字被纸边切断时必须有可读副本；色面到纸边时正文仍守版心 |

## 四、明确不做什么

- 不加圆角、阴影、渐变：层级由字阶、色面、网格建立。
- 不给每页加顶部横线或浅底卡片：说明块靠位置分组，不靠框。
- 不用生成图代替素材：六张照片全部是 `sources/assets.json` 登记的公有领域/CC0 原件。
- 不为凑满页面放大装饰字；正文不缩字换容量。

## 五、用户确认

- 本节由执行者（agent）在 2026-10-23 的自评中记录，**不是**独立 reviewer 的确认。
- 变奏章（93–100）经用户追问后重排两轮：先按视觉主张统一骨架（被否：压小了手势），
  再回到字阶与基线（当前版本）。
