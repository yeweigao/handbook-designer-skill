# 受控变量 · Controlled Variance

一份视觉主张，用于把"同一系统的不同表达"做成一件可反复观看的东西。

## 一

每一次观看都是一次实验：只改一个量，其余全部锁死。版面不是容器，是仪器——它的刻度必须可信，它的边界必须清楚，它的重复必须准确到可以被预期。观众不必读到说明，就能感到这里有人在称量什么。

## 二

空间先于形式。同一副骨架贯穿全部画面：同一条左轴、同一条基线、同一圈安全边距。画面里至少有一处抵达纸边，让眼睛知道边界在哪里；其余留白必须像抽成真空，安静到能听见比例。形状只从决定里长出来——一个切角、一道硬边、一次位移——绝不成组地出现。任何可以被移走而不损失意义的元素，都应当被移走。

## 三

色彩是纪律，不是情绪。纸白、墨黑、一个信号色；第三色只在它承担了不可替代的区分任务时入场，且每次入场都要被重新解释。材质必须是真实的：照片的颗粒、油墨的硬边、纸张的纤维。不用渐变假装深度，不用阴影假装层次，不用滤镜假装完成度。克制不是少做，而是每一处都做过又收住。

## 四

尺度必须悬殊到不可能被误读：一个字大到必须被切掉，一行注记小到必须凑近。中间地带没有安全感，因此要少用它。节奏由重复建立——细线、编号、坐标标记——像标本册的边栏，安静地证明这不是随手摆出来的。重复不是装饰，是把"同一套规则"变成可见的证据。

## 五

工艺是唯一无法伪造的东西。每个转角、每处对齐、每段字距，都该看得出被反复推敲过：这是一件耗费了数小时、被一毫米一毫米校对过的作品，出自把这件事做到极致的人之手。第二遍不再增加任何图形，只收紧已经存在的：把 12px 的间隙调到 11，把 90% 的黑调到 92%，把一处犹豫删掉。最终它应当像一页从某个不存在的研究所里流出的图版——冷静、准确、值得反复看，却始终不解释自己在说什么。

## 落版约定（这一章实际使用的数值规则）

主张管判断，不管模数。落版时只用系统已有的数值：

- 字号只用字阶表上的值：11 / 13 / 14 / 16 / 20 / 24 / 32 / 46 / 64 / 112 / 196 / 280。裁字与填图字允许取最大字阶的整数倍（560 = 2 × 280），且被放大的字必须是重复装饰，另有可读副本。
- 高度与间距落 28px 基线：高度取 28 的倍数（196 = 7 行、588 = 21 行），间距只用 0 / 7 / 14 / 28 / 42 / 56 / 84 / 112 / 168。
- 能用原子就不写内联：内边距 `fl-p-3`、间距 `fl-gap-2`、外边距 `fl-mt-3`，不手写 26px 这类数字。
- 不新建组件：署名类信息用已有的 `fl-meta / fl-foot / fl-legend`，不为某一页临时发明一条"署名带"。
- 允许一页只有一个手势；不允许为了"成套"把八页塞进同一个模数——那是模板，不是主张。
