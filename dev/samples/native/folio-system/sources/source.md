原创教学示例 · 非旅行指南

01 / 停留

# 先停一下，
再给风景命名。

看到一棵树，可以先不问它叫什么。试着描述它怎样进入画面：靠近哪一边，挡住了什么，又把哪里留给光。

我们常常很快地辨认一幅照片：这是森林，那是海岸。名字让交流变得方便，也容易让观察提前结束。再停留片刻，画面里还会出现更多关系：枝叶的疏密、水面的明暗，以及前景和远处之间的距离。

不必立刻解释每个细节。先写下能指给别人看的东西。例如，“左上方的枝叶遮住了天空”比“这里很有生机”更容易核对。它把一句感受变成了可以继续讨论的起点。

描述也不需要覆盖全部。选一个你最在意的关系，沿着它往下看：一条边界如何转折，一小片亮处怎样被暗处包围，或一处空白让视线停在哪里。

随后再写下你的判断，并把两者分开。“画面里的水很平静”是一种阅读；“水面上有连续的浅色反光”则是另一种描述。判断可以保留，只要读者知道它从哪里开始。

这本小册把同一张照片放进不同边界，也让一张照片延续到相邻的两页。你可以比较：哪些线索被保留，哪些暂时离开了视野，文字又在什么时候介入。

最后，给自己留一个还没有答案的问题。观察并不总要收束为结论。有时，一句准确的问题就足以让下一次观看有所不同。

把“我觉得”，接在“我看见”之后。

02 / 描述

# 从画面，到问题

先写一句可以在照片上指出位置的话，再问一句需要继续观察的话。以下是练习句式，不是对照片拍摄地的事实认定。

看什么

可以这样描述

接着这样追问

位置

主体靠近画面的右边，左侧保留了一片较空的区域。

如果把主体移到中央，视线会怎样走？

明暗

亮处被较暗的枝叶围住，边缘仍能分辨出细节。

先吸引你的是最亮的地方，还是最清晰的边缘？

尺度

近处的叶片占据更多画面，远处的树干显得更细。

有没有一个细节，能帮助你感受远近？

边界

一部分枝叶在画面边缘被截断，方向仍然可见。

画面之外，哪些内容值得再去查看？

随手练习

任选一幅图，写下一句描述和一句问题。先不要查答案；请同伴只根据你的文字，找到你指的那一处。

03 / 远近

# 把目光，放近一点。

水与石块之间，可以沿着亮暗交界追踪视线。

抬头看，一条坡面把视线引向远处。

低头看，叶片的方向与纹理进入画面。

整幅风景与局部细节可以放在一起阅读。试着先看大图，再回到旁边的小图；留意你的描述是变得更具体，还是出现了新的问题。

本页照片来自不同拍摄地点，编排用于观看练习，不表示同一地点或同一段旅程。

04 / 取景

# 同一张照片，
两种停留。

向左取景 / 岩壁与水面占据视野。

向右取景 / 灯塔与坡面成为线索。

# 你先看到了什么？

先用一句话描述左图。再看右图，看看这句话是否仍然合适。

# 什么离开了画面？

回到封面的完整取景，找出两次裁切各自省略的线索。

照片相同；取景改变了我们先遇见的内容。

05 / 延续

# 一片林，

让目光穿过书脊

从左侧枝叶开始，沿着亮处向右看。暂时放下文字，让眼睛自己选择下一处停留。

FOLIO / 再看一次

# 带走一个问题，
留下观看的余地。

下一次遇见一幅风景，先写下你看见的，再写下你想知道的。让这两句话之间，留一点空白。
