# 看见之间 · Folio 观察小册

- 用途：以一册真正可阅读的图像观察读物，检验 Folio CSS 的文字、信息和摄影能否共用同一套原子与版式。
- 内容：为本样册编写的原创教学文字，原稿保存于 `sources/source.md`，段落索引见 `sources/segments.json`。句式是观看练习，不作为拍摄地点的事实介绍。
- 读者任务：区分图像中的可指认描述与个人判断；比较取景、大小和跨页连续视野怎样改变阅读顺序。
- 内容模式：carry。正文冻结为上述自写原稿后排版；不冒充用户提供的原文或现实活动。
- 画布：A4，四边 3mm 出血，右页起排，单语言 zh-CN，电子版装订。第 6 页左、第 7 页右为一个真实连续跨页。
- 设计：Folio CSS 1.0.0 的同一字体、网格、间距、颜色与图片规则贯穿全册；样册作者 CSS 只负责表格列宽与跨页图像的纵向位置。
- 素材：4 张已有本地真实照片。森林图为 CC0 1.0，其余三张为公有领域；完整来源、署名与许可保存在 `sources/assets.json`，封底有对应署名。
- 图像含义：来自不同地点的照片是观看练习材料，照片组合不暗示同地或同一行程。
- 视觉取舍：用字号、比例、对齐和留白建立层级。表格横线承担行列定位；不以装饰性侧边线与底色提示框代替编排。
- 构建：使用已安装的浏览器与项目现有工具，不安装任何依赖。技术检查与作者视觉复核的实际状态记录在 `experience.md` 及 `.qa/`。
