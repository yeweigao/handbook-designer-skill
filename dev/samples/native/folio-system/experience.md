# 样册验证记录

本册为 Folio CSS 1.0.0 的首轮组合样册。最终生成的家族 CSS 已完成实际渲染、技术检查、8 页及全部面对页审稿。构建 `bebe29aa0866`，技术全 pass，作者复核可交付；记录见 `.qa/visual-review.md`。

## 已落实的约束

- 文字、信息、摄影使用同一个 Folio 家族；未定义单独 Photo 皮肤。
- `book.css` 仅包含本册表格列宽和全景图纵向窗口等组合需求，没有另写一套字号、颜色、间距或图片裁切规则。
- 第 6、7 页明确声明同一 `data-spread`，左页在前、右页在后；共享同一素材与图像坐标。图上不压文字，留在纸面上阅读。
- 所有正文有来源 ID；图片有可编辑 ID、素材 ID 及来源许可。图注说明异地照片的组合用途。
- 所有文字使用家族实际提供的常规/粗体，未假造斜体或额外字重。

## 最终复核范围

- 八页文字无溢出、原文覆盖、字号/对比度、字体嵌入及图片清晰度。
- 双栏正文行长与段落密度；比较表每行的空白是否足够。
- 大小图之间的视觉关系；第 5 页左右取景是否清晰表达不同关注点。
- 第 6、7 页在裁切线处的连续性、纵向对齐和出血重叠。
- 深色封底所有层级的可读性与署名完整性。

## 可迁移观察

- 布局默认值需低优先级，才能被单独原子覆盖；浏览器回归覆盖真实组合而不只检查类名存在。
- 固定高度的图组仍应显式约束图框宽度，避免内在宽高比把列撑开。
- 跨页坐标按成品宽度移动；保留两侧出血后再看裁切拼接，不能按媒体宽度偏移。
- 表格增大行间、平衡断行改善了首轮末行孤字；仍需随实际内容复核，不能以此推成所有表格的固定参数。
