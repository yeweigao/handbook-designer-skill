# 页面计划

| 页 | 阅读任务 | 构图 | 共享能力 |
|---|---|---|---|
| 1 | 封面：明确这是观察练习 | 两行大字与窄侧注并列，海岸横幅，底部出版信息 | 六轨 grid、4+2 span、hero 字级、wide 图框、flex 留白 |
| 2 | 连续阅读：先描述，再判断 | 大标题、短导语、双栏正文，结尾一句开放引文 | split、prose 段落节奏、measure、字体层级 |
| 3 | 信息检索：位置、明暗、尺度、边界 | 三列表格；仅用横线建立信息行，末尾小练习 | rule、spacing、body/key/display、marginalia |
| 4 | 看远近：大场景与细节并置 | 一大两小照片组，独立图注，文字与来源注 2+1 分列 | photo-essay、portrait/square 图框、sidebar |
| 5 | 比较取景：同图不同焦点 | 同一原图两幅竖裁，左右取景，成对问题 | photo-pair、focus-left/right、comparison |
| 6 | 跨页左：让视野延续 | 标题在纸面，通栏森林图横向出血，说明在图下 | panorama、safe area、same image field |
| 7 | 跨页右：回到一个细节 | 延续左页的同一图像坐标，标题与图下说明保持对齐 | panorama、data-side、同一纵向窗口 |
| 8 | 结尾与署名 | 深色纸面、大字结语、双栏版权信息 | surface-dark 完整继承、display、split、caption |

跨页使用同一文件、同一缩放、同一纵向窗口；右页偏移一个裁切宽度而不是一个含出血的媒体宽度。第 6、7 页保留独立 PDF 页面；不以合并大画布伪装跨页。
