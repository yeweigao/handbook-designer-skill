# 修订记录 · 山海自然探索营

- 首轮：第一章开篇的序号与英文眉标压在亮云上，对比度不足。→ 章节压暗层加高到 82% 并加深。（证据：.qa 首轮 measure）
- 第二轮（首次看栅格）：英文版里宋体/黑体标题中的 ’ 显示为全角宽度（"won’ t"）；第 3、5、7、9、11、15 页下部大片空白。→ 家族升 v1.1：英文版启用 pwid 比例标点（必须写到每个元素上，`font` 简写会重置它）；空页改为把正文/引文/备注压到页底、卡片撑满余下版面、清单放大到导语字号。
- 第三轮：卡片序号用 `-webkit-text-stroke` 描边字，导致 PDF 出现 Type 3 字体，对比度也不足；2×2 大数字行高 .9 与说明文字重叠。→ 改实心赭色数字；大数字行高 1.2。适用边界：任何描边/镂空文字都会变 Type 3，家族里不要用。
- 第四轮：封面裁切处有黄色告示牌和一只鹭压在标题下。→ `object-position: 76%` 让灯塔进画面；眉标压在亮岩上，压暗层加三段渐变。英文自动断词的连字符在宋体里是全角（U+2010）。→ 家族加 `hyphenate-character: "-"`；大号宋体导语关掉自动断词。照片署名里 Flickr 账号名被截断（"US Fore"），改为完整机构名。
- 第五轮：技术检查全过；视觉审稿可交付。
