# 节奏模板：整本书的页序

先按用途和篇幅挑一个模板，把 plan.md 里的原文段落按原文顺序填进去；原文段落多就重复“章节”那一组，少就删掉可选页。
页序只是起点：原文顺序优先于模板顺序（不为了套模板挪动原文）；原文里没有的内容不要为了填页而编。

页内与整册的节奏设计见 `references/composition.md`；以下页序是起点，不能把“每隔几页换色/插大图”当成阅读节奏。规则（引擎会检查或自动处理的打 ✓）：
- 基础内容版式会自动轮换底色 ✓（layouts.md §0）；编辑变奏默认纸底，按页面任务显式设 `surface`。图片原色/双色调按项目决定。
- 封面、封底可用 `FULL`（`folio: false`）；摄影先行的封面也可用 `PHOTO_OPEN`。
- 密集内容之后安排有内容依据的停顿：可以是短摘句、图版或大图，不为凑节奏补无关图片。
- 相邻叙事页可变换跨栏、图像体量与密度；查阅区和同一篇文章的 `READING` 续页允许重复。同版式自动镜像只适用于原基础版式，编辑变奏保持稳定阅读方向。
- 骑马钉页数是 4 的倍数 ✓（构建时提示余数）。凑页先挪内容；宣传册补页用 COLLAGE（现场图）或 FULL（章节页），不用空白页。
- 跨页（SPREAD_*）从偶数页开始 ✓。

## 宣传册 brochure（招生简章、项目介绍、品牌画册）

**8 页**
| 页 | 版式 | 放什么 |
|---|---|---|
| 1 | FULL | 封面：名称 + 一句定位 + 关键数字 |
| 2 | ONE | 致辞 / 是什么 |
| 3 | CARDS | 亮点（num: true） |
| 4 | STAGGER | 2–4 条主线 / 模块 |
| 5 | GRID | 日程、费用、时间轴 |
| 6 | COLLAGE | 往届回顾 / 现场图（没有图 → MIX 或 TWO） |
| 7 | CARDS (style: line) | 常见问题 / 报名须知 |
| 8 | FULL | 封底：联系方式 + 二维码 |

**12 页** = 8 页 + 第 2 页后插 `FULL`（章节页）· 亮点后插 `TWO`（图文交替）· 回顾后插 `MIX`（团队 / 安全）· 再加一页 `GRID` 或 `CARDS`。

**16 / 24 页**：封面 FULL → 目录（GRID `toc: auto`）→ ONE 致辞 → 每章一组：
```
FULL + `index: '01'`（章节页：巨型章节号压出页边；或照片版式 SPREAD_P 跨页） → 2–4 页内容（CARDS / STAGGER / TWO / MIX / GRID 轮换）
```
→ 末尾 GRID（费用、报名）→ FULL 封底。24 页约 4 章。

## 指南 guide（家长手册、新生手册、入职手册、活动 / 会议指南）

**12 页**
| 页 | 版式 | 放什么 |
|---|---|---|
| 1 | FULL | 封面 |
| 2 | ONE | 欢迎信 |
| 3 | GRID | 关键日期 / 日程（timeline + table） |
| 4 | CARDS | 你需要知道的几件事 |
| 5 | TWO (columns) | 规则 / 须知 / 对比 |
| 6 | FULL | 章节页 |
| 7 | STAGGER | 地点 / 部门 / 流程介绍 |
| 8 | GRID | 详细表格（课表、费用、物品清单） |
| 9 | MIX | 人员 / 安全 / 服务 |
| 10 | CARDS (style: line) | 常见问题 |
| 11 | GRID | 通讯录、紧急联系（table） |
| 12 | FULL | 封底 |

指南以读为主，[留白] 提示可以不处理；连贯长文优先 READING，查阅文字优先 TWO / GRID，不要硬塞进 CARDS。

## 任务册 workbook（研学手册、练习册、任务单）

读者要在上面写字，所以内容页用**进阶模式**的照片版式 + 书写块（blocks.md：field / lines / fill / table / box / sign），样例 `templates/book.study-trip.zh.yaml`。
内容版式只用在阅读页：封面 FULL、致辞 ONE、行程总览 GRID、本单元目标 CARDS、往届作品 COLLAGE。
节奏：每个单元（一天 / 一章）= 一个跨页（SPREAD_H 或 SPREAD_OPENER）+ 1–3 页任务页（T / SL / HOLE 轮换），单元之间不连用同一版式。

## 精简版（折页、展会派发、朋友圈长图）

4–8 页：FULL 封面 → CARDS 亮点 → GRID 日程 + 费用 → FULL 封底（报名二维码）。只留最打动人的内容，其余写进回复让用户确认删哪些。
