# 内容版式库（标准模式）

先设计内容的阅读顺序，再选对应的网格组合。**不手写尺寸、坐标、颜色、装饰**：版面几何与溢出处理由引擎（`hb/canon.py` + `hb/flow.py` + `hb/fill.js`）承担。版式与主题的分层及变奏方法见 `references/composition.md`。
**一个引擎，所有风格、所有版式共用**：8 种基础内容版式、6 种编辑变奏和照片版式（blocks.md）排在同一张网格上，用同一套字号档、行宽规则和放不下时的处理顺序；主题承担字体、颜色、线条与图像气质。
效果图：`dev/gallery/layouts_overview.jpg`（8 种一览，中英并排）、`dev/gallery/palettes_overview.jpg`（当前克制配色）、`dev/gallery/grid_xray.jpg`（网格透视）、`dev/gallery/L_<版式>.jpg`。
可运行的整本样例：`templates/book.layouts.yaml`（16 页，中英双语一份 yaml，8 种版式全用到）。

## 0. 引擎怎么排（知道就行，不用管）

**网格：所有尺寸都从正文字号推出来。** A4 = 794 × 1123px（1:√2）。正文 16px（印出来 12pt，小四）、行距 28px；一栏 = 5 个字 = 80px，栏间 = 2 个字 = 32px，6 栏 = 40 个字；版心 32 行 ≈ √2 × 版心宽。字号档：13（标签、图注）· 16（正文）· 23（导语、条目标题）· 33 · 47（页标题）；展示大字 56 · 72 · 96 · 120 · 160（封面、章节页标题按栏宽量出来）。每个元素的边都落在栏线和 28px 行线上，块与块之间隔整行——中文每行是整字，不会出现半个字的缝。英文版与中文版均用 16px 正文；不靠缩小英文正文换取版面容量。
**行宽**：中文正文每行 19–40 字（3–6 栏）；23px 导语只在 ≥ 4 栏宽的栏里用，窄栏回到正文字号；西文单栏段落按当前字号限制到约 60ch；宽区的连续长段落自动分成两个阅读栏，不靠通栏长句填空。短标题可以通栏；短信息组不因累计字数多就被截在两个栏尾。
**按语义选择流向**：导语默认保持完整的阅读块，不自动从句中间转栏；ONE 的正文可写 `text_flow: keep / columns / auto`。内容块 `p`、`letter` 可写 `flow: keep / columns / auto`，keep 仍会在当前栏内自然换行，columns 则明确使用两阅读栏。使用导语字号的p同样默认keep，仍可显式选择columns。统计及时间地点先结构化，适配流程见 adaptation.md。
**浏览器断行**：正文、列表与副题启用 `text-wrap: pretty`，保持原有对齐方式。该属性只优化浏览器选择的断行，不能修复手工断句或错误的信息块；各引擎算法不同，当前 PDF 导出使用 Chromium，不能以 WebKit 预览代替实际 PDF 验收。
字多的练习册、长文写 `book.body: 14`：回到紧凑网格（正文 14px / 行距 24，一栏 6 字 = 84px，栏间 28，38 行，印出来 10.5pt 五号）。A5、小红书画布固定用紧凑网格。
一页放不下时，引擎按这个顺序让出空间（每一步都还在行线上），正文字号始终不变：
1. **插图先让**：这一页出问题的文字栈里的图按整行缩矮，辅助图最多缩到原高的一半左右；主图（`role: primary` 或未手写高度的宽图）至少保留约四分之三，容量不足应重排；
2. **再让空白**：卡片之间的行距收到 0（卡片自带顶线），块与块之间超过 1 行的间距逐行收到 1 行，`space` 块收到 0；
3. **再让书写线**：多行书写线（`lines: 3` 这类）逐行少，每组至少留 1 行（构建时报 `[书写线收紧]`）；
4. **缩大标题**：标题按 0.86 倍一档档缩，最多 6 轮；
5. **收辅助字号**：这一页的导语、小标题、标签、条目编号小一档（报 `[字号收紧]`）。
还放不下才报溢出，并告诉你怎么拆页。报了 3、5 的页最好拆开，书写空间、字号才是原样。

**文字栈 + 吸收体：同一套版式排中文、英文都不出问题。** 文字不写死在第几行，而是成组钉在版心的上沿或下沿；照片和色块是“吸收体”，长到文字栈上方两行为止。英文比中文长 30–60%，变的主要是照片和色块的大小；主图仍有最小高度，容量不足会报错，不能因此假定留白或构图合格。

**大标题撑满栏宽。** 浏览器里量出标题最长一行，缩放到正好撑满给定的栏宽（有上下限）；能在空格、`·`、`，` 处折成两三行而且大很多时就折行（中文不会拆词）。想自己定折行，在标题里写换行：`title: "山海\n自然探索营"`。

**放不下时自动处理。** 文字超出版心、超出色块、越过它该停的位置（比如章名压到下面的照片格）、互相压住、条目行放不下、图片被挤得太小 → 按上面的顺序让出空间；还不行才报 `[溢出] [重叠] [图太小] [标题太长]`，并告诉你怎么拆页。

**纸面节奏。** 默认以纸色与浅底为主，按页面任务安排照片、主色或深墨纸面；不为“每页不同”机械切换大色块。Swiss 使用一个强调色，字重规则见 style.md §2.2；Photo/Editorial 依靠字体分工与摄影关系建立层级。

**装饰只用信息本身。** 巨型章节号（FULL `index`）、巨型条目数（CARDS 的“6”）、大号编号、关键数字——都来自内容，不放随机几何。

**照片自动处理。** 发灰发白的照片（褪色、过曝、雾面）自动做成 A/B 双色调，与项目的颜色角色统一；`book.duotone: all` 全部做，`off` 都不做；单张写 `{src: a.jpg, duo: true / false}`。没给照片的图片位：照片风格排成主题色区 + 大号编号（像是有意的设计，构建时提示补图）；无图风格自动生成风格插画；瑞士、风格派是一块安静的色块，不写编号。
**插图的纪律**：照片和插画只放在网格里的一格（或满版出血），边落在栏线 / 行线上（photo 风格的照片在这条线上淡进半透明纸面，其余风格硬边）；浅色插画上要写字时，插画停在文字上方一行、字落在干净的纸上，不和插画叠在一起。

## 1. 先看内容形状，再选版式

| 内容长什么样 | 版式 | 截图里的叫法 |
|---|---|---|
| 封面、章节页、封底；一句话 + 几个大数字 | `FULL` | 全屏型 |
| 致辞、简介、一段有气质的话（≤ 500 字） | `ONE` | 单栏式 |
| 2–9 条并列的短条目：亮点、服务、团队、FAQ | `CARDS` | 卡片式 |
| 2–4 个模块，每个有标题 + 一两句话 + 一张图 | `STAGGER` | 错位式 |
| 左右两三栏文字（须知、对比）；或 4–8 条带图的条目 | `TWO` | 双栏式 |
| 目录、日程、费用、时间轴、关键数字、大量条目 | `GRID` | 网格型 |
| 3–7 张现场照片 + 一句话：往届回顾、活动花絮 | `COLLAGE` | 自由型 |
| 一张主图 + 2–3 段文字；或 2–3 段文字 + 两三张图 | `MIX` | 组合型 |

`plan.py` 已经按这张表给每段原文建议了一个版式（plan.md），可以直接用，也可以改。

## 2. 所有版式共有的空位
```yaml
- layout: CARDS
  kicker: Highlights · 项目亮点     # 小标签（英文 + 中文都行，算装饰）
  title: 六个关键词                  # 页标题（原文的标题）；"第一行\n第二行" 自己定折行
  en: Six Keywords                  # 可选：副题（斜体）
  intro: 一句导语（原文）             # 可选
  header: [左页眉, 右页眉]            # 可选
  surface: A                        # 可选：手动指定主底 paper / A / B / image（一般不写，引擎自动轮换）
  mirror: true                      # 可选：手动镜像（相邻同版式时引擎会自动换）
  note: 原文第 3 节                  # 不渲染，给自己记对应关系
```
条目（cards / items / columns / sections）每项三种写法都行：`标题` · `[标题, 说明]` · `{k: 眉标, t: 标题, x: 说明, items: [要点…], img: 图}`。
`x` 写成列表就是带短线的要点；**原文的 • ▶ ✓ 符号不要抄进来**。
强调：标题或正文里用 `**…**` 包住的字显示成强调色（如 `title: 下次不会排版，先套这个**公式**。`），一页最多一处，不算改原文。
图片写法：`a.jpg` 或 `{src: a.jpg, focus: [.5, .3], duo: true}`（focus 只在主体被裁掉时才写）。留空 = 要一个图片位、先占位。`ai:编号` = AI 配图位（见 images.md）。

**中英双语**：任何文字都可以写成 `{zh: 中文, en: English}`，并在 book 里写 `langs: [zh, en]`。`run.sh` 一次构建两种语言，各自跑完整检查，再出逐页对照图 `.qa/compare_*.jpg`。英文里有逗号、冒号、问号时整段加单引号：`en: 'Five days, four nights'`（不加会被 YAML 拆开，构建时会报错指出位置）。

## 3. 八个版式

### FULL 全屏：封面 / 章节页 / 封底
```yaml
- layout: FULL
  image: cover.jpg            # 有照片：满版照片 + 一块出血主题色区，书名压在里面（色块高度随书名定）
  kicker: Horizon Nature Discovery Camp
  title: "山海\n自然探索营"
  en: 五天四晚 · 2026 年 7 月
  intro: 海岸地质 × 森林生态 × 天文实验室
  stats: [['5', 天 4 晚], ['7–9', 年级], ['24', 人小班]]   # 可选，最多 4 个；数字加引号
  folio: false                # 封面、封底不要页码
```
- 不写 image（照片风格）：整页主题色的字体海报，图形按主题处理（Swiss 无大圆装饰），标题落在黄金分割附近；`deco: false` 去掉“日”。
- **章节页**：加 `index: '01'` → 没照片时巨型章节号压出页边、标题落在黄金分割附近（瑞士单色档收为320px章节号、章名最多两行，避免编号压过内容）（下面还有导语、正文时章节号自动从 480px 降到 320px，给字让出行数）；有照片时章节号是文字栈里的一个 144px 大数字，和标题一起钉在版心下沿（白字，照片自动压暗）。目录页 `toc: auto` 会自动收集所有章节页。
- 封底加 `bottom: [{qr: 'https://…', caption: 扫码报名}]` 放二维码。

### ONE 单栏：致辞、简介
```yaml
- layout: ONE
  kicker: A Letter · 致家长
  index: '01'                 # 可选：标题上方一个大号编号
  title: 让课本里的世界走到眼前
  text: [第一段原文, 第二段原文]
  quote: 孩子带回来的不是纪念品，而是一套看世界的方法。   # 可选：和正文左右并排
  by: 项目主任 · 林老师
  image: letter.jpg           # 可选：顶部出血大图，长到标题上方两行
```
没有 image：上方一大块主题色区，标题钉在色块底部（海报感），正文钉在版心下沿。多段中长文自动分两栏，短文使用整个版心；超过 ~500 字换 TWO（columns）。

### CARDS 卡片
```yaml
- layout: CARDS
  title: 六个关键词
  num: true                   # 默认有 01 02 编号；num: false 关掉
  count: true                 # 默认有巨型条目数（“6”）压出页边；count: false 关掉
  stats: [['12', 年], ['3000+', 名学员]]   # 可选：标题下一排大数字
  style: line                 # 可选：线条式（FAQ、须知）
  cards:
    - [海岸地质, 走进潮间带与海蚀崖，跟地质导师完成一次岩层采样。]
    - {t: 森林生态, x: 在保护站了解本土物种……, img: forest.jpg}   # 任何一张写了 img → 每张卡片都带图位
```
2–9 张：2/3 张一行，4 张 2×2，5–6 张 3×2，7–9 张 3×3（`cols:` 可改）。变体自动轮换：上半页主题色区 + 下面卡片 / 整页主题色；带图时页头在一条色带里、图片按行平分剩下的高度。超过 9 张 → 拆两页。

### STAGGER 错位
```yaml
- layout: STAGGER
  title: 地质 · 生态 · 天文
  items:
    - {k: Geology, t: 潮间带与岩层, x: 原文……, img: coast.jpg}
    - {k: Ecology, t: 森林与栖息地, x: 原文……, img: forest.jpg}
    - {k: Science, t: 天文与光学实验室, x: 原文……, img: lab.jpg}
```
2–4 行，棋盘式图文交替：图片出血到页边、文字格在栏线上，行高按文字多少分配（字多的行高一些，图片吸收剩下的）。自带 01 02 编号（`num: false` 关掉）。三四行时自动使用紧凑编号、条目标题和边距，正文仍用全书正文字号。每条建议 ≤ 120 字，以实测容量为准。

### TWO 双栏
```yaml
- layout: TWO                 # A：左右两三栏文字（2–3 栏）
  title: 报名须知
  columns:
    - {t: 适合的学生, items: [7–9 年级在读, 能用简单英语交流]}
    - {t: 出发前准备, items: [有效期 6 个月以上的护照, 一份签署的安全承诺书]}
- layout: TWO                 # B：带图的条目 → 两列图文格子（4–8 条），图片上下交替
  title: 一天是怎么度过的
  items:
    - {t: 早餐与晨会, x: 七点半在营地餐厅用餐……, img: breakfast.jpg}
```
A 型：上方主题色区装标题（标题很大、钉在色块底部），栏文字钉在版心下沿；写了 `image` 就换成顶部出血照片。

### GRID 网格
```yaml
- layout: GRID
  title: 五天行程
  intro: 行程以营地安排为准。
  timeline: [[第 1 天, 抵达营地 · 开营仪式], {k: 第 3 天, t: 森林生态保护站, x: 巡护员带领, hot: true}]   # hot: 重点标出
  table: {head: [项目, 说明, 费用], rows: [[学费, 课程、导师, 包含], [交通, 营地往返大巴, 包含]]}
  facts: [['42', 公里徒步], ['136', 种植物]]      # 关键数字
  items: [[标题, 说明], …]                       # 多栏小条目
  notes: [报名截止日期为 2026 年 5 月 31 日, 满 16 人成团]   # 小字备注
- layout: GRID                # 目录
  title: 目录
  toc: auto                   # 自动收集带 index 的 FULL 章节页（编号、标题、副题、页码）；也可手写 [[01, 标题, 副题, 页码], …]
```
区块**按 yaml 里写的顺序**从上往下排（= 原文顺序）。放不下时时间轴自动改成紧凑式。只有 `facts`（+ `notes`）时，数字做成整页主角（2×2 巨型数字）。

### COLLAGE 自由拼贴
```yaml
- layout: COLLAGE
  title: 2025 年的 48 位同学
  text: 五天里他们走了 42 公里……       # 一两句，≤ 80 字
  images: [a.jpg, b.jpg, c.jpg, d.jpg, e.jpg]   # 3–7 张
  captions: [海岸速写, 保护站, 实验日, 森林徒步, 成果展]   # 可选：图上只放编号，图注集中写在文字模块里
```
整页满版照片拼接（只留 3px 细缝），格子边落在栏间中线和行线上，一块文字模块装标题。按张数选预设构图，相邻页自动镜像。

### MIX 组合
```yaml
- layout: MIX                 # hero：一张主图 + 主题色带装标题 + 1–3 栏文字 + 可选引语
  title: 陪伴他们的人
  image: team.jpg
  sections: [{t: 营地带队老师, x: 原文……}, {t: 科研导师, x: 原文……}]
  quote: 我们不替孩子找答案……
  by: 科研导师 · 周博士
- layout: MIX                 # side：2–3 张图竖叠在切口一侧（满版出血），文字在订口一侧三栏
  title: 每一步都有人在
  images: [doctor.jpg, phone.jpg]
  sections: [{t: 医疗, x: …}, {t: 通讯, x: …}, {t: 保险, x: …}]
```

## 4. 数量限制和自检
- **数量限制**：CARDS 2–9、STAGGER 2–4、TWO items 2–8 / columns 2–3、COLLAGE 3–7、MIX sections 1–4，超出直接报错并告诉你怎么拆。字数明显超出时构建时就提示。
- **镜像轮换**：相邻两页同一版式，第二页自动换变体（底色、图文方向、拼贴构图）。
- **浏览器里的自检**（`fill.js` → `shot.js` → `doctor.py`）：文字出版心、出色块、互相压住、条目行放不下、图片被挤小、标题缩到最小还放不下。先自动缩标题，仍不行才报错。
- **对比度**：色块和照片上的文字由 QA 实测，小字要 ≥ 4.5:1（引擎按 5:1 选色留余量）。

## 5. 和照片版式混用
内容版式和照片版式（POSTER、T、SPREAD_H… 见 blocks.md）是同一个引擎、同一张网格，可以在同一本里随意混用：有好横图时，章节开头用 `SPREAD_P` / `SPREAD_OPENER` 跨页大图（从偶数页开始），内容页用本库。
需要读者书写的任务册（field / lines / fill / table）用照片版式 + 内容块（blocks.md），内容版式只用在封面、致辞、亮点这类阅读页。

## 6. 新增的自检与写法
- **装饰大字压字**：巨型章节号、条目数这类装饰大字，如果真正有墨的部分压到了文字，报 `[重叠] 装饰大字压到了文字`（按字形量，不按行盒）→ 缩短标题，或 `count: false` / `deco: false`，或 `mirror: true`。
- **每页 `job:`**：写这一页让读者做什么 / 知道什么，用 `purposes/<kind>.yaml` 的角色词开头（`job: why · 三个理由`）。`rhythm: anchor | dense | breathing` 可以覆盖 lint 的自动判断。
- **品牌包**：`logo: true / false`、最后一页 `contact: false`（style.md §7）。
- **画布**：`book.canvas: a5 | xhs` 时网格变成 28 行、栏更窄，装饰大字按比例缩小；照片版式不能用（delivery.md「画布」）。

## 7. 图片角色与真实可见尺寸
`image: {src: team.jpg, fit: contain}` 可以在内容版式里保留合照全幅；照片不是因为瑞士版面配色就必须变黑白，按 brief.md 的 duotone 决定执行。自由 `figure` 不写 h 时按原图纵横比和所在栏宽推导高度，再吸到整行；`role: primary` 保留主图体量，`role: supporting` 把辅助竖图限制在10行以内。原海报、截图用 contain，并检查内部字是否可读；重要旧海报可以独立成图版页。图片实际可见面积、主体裁切及 PDF 导出一致性见 review.md。

用户要求图片接纸边时，在 `book` 写 `image_bleed: both`；整版心的照片/插图和图组会横向出血，独立图版可写 `bleed: page`。正文行长不随图片宽度扩大，侧栏照片也可用 SL/SR 接上、下和外侧纸边。图表、二维码和logo是功能图，应保全内容，详细写法见 blocks.md。

## 8. 编辑变奏：自然流动的六栏组合

以下六种是布局，独立于 `book.style`，均支持 `surface: paper / A / B / dark`（默认 paper，不自动交替底色）。沿用网格随 a4/a5/xhs 缩放，容量按实际字号测量；换小画布时需要按内容拆页。前五种共用 `title / kicker / sub`，标题可用换行指定停顿；READING 的篇名规则见下方。

| layout | 数据与结构 | 适用范围 |
|---|---|---|
| `RHYTHM` | `intro` 侧导语；`text` 段落列表，首段四栏，后续完整段落三栏续读；可加 `quote / by` | 有完整论述和重点句的短文章；没有摘句可省略，不自动编造 |
| `MARGINALIA` | `sections: [{t, x, note_title, note}]`，主文四栏＋对应旁注两栏；`intro` 可选，`quote / by` 可在首组后停顿 | 解释、术语、观察提醒。每组按两侧较高者推进，旁注不漂移到下一段 |
| `PLATE` | 实际 `image`（默认 contain）；`caption`；`annotations: [{k, t, x}]`；可选 `intro / text` | 图版、标本、器物、示意图。四栏主体＋两栏解释。k 默认 01 起，不会自动在图上加标注 |
| `SEQUENCE` | 恰好三个 `items: [{img, k, t, x}]`；第一张四栏主图，后两张三栏图错位；img 可用 `{src, fit, focus}` | 主场景与两种补充视角；图像必须各有信息价值，不能用三张无关图填槽 |
| `PHOTO_OPEN` | 实际 `image` 顶部及左右出血主图先出现（默认 `bleed: edge`，可显式 `inset`），`caption` 随图；下接四栏 `title / kicker / sub` 与两栏短 `intro`，可选短 `text` | 摄影开场、章节邀请；图下文字共同承接场景，不在图上叠长文 |
| `MASONRY` | 六个 `items: [{img, caption}]`，按列先上后下；`bleed: edge / inset`（默认edge） | 六轨合并三条瀑布图流，图先文后；从页顶进入，接缝错开、底边收齐，01—06图注集中在标题下并关联对应图 |
| `CONTACT` | 实际 `image` 主图、`caption` 及六个 `items: [{img, caption}]`；`bleed: edge / inset` | 一幅宽景＋两行六图索引，全部图位铺满，尺度形成主次 |
| `READING` | 四栏 `text` 正文从版心顶部开始；两栏侧记放 `title / kicker` 或 `series_header`，可选 `notes` 列表；首页可加 `intro` | 连贯文章、明确分配段落的续页。侧记稍后进入视线，正文保持一条稳定阅读线 |

`RHYTHM` 始终保留两栏侧导语区，应提供短 `intro`；省略时保留留白，首段不会自动改为全宽。`PLATE` 的编号须与源图中的标记对应；没有标记时可用语义 `k`（例如“轮廓”）。图版默认 `image.duo: false` 保留原色，可显式覆盖；`SEQUENCE / PHOTO_OPEN` 照片沿用全书的 duotone 设置。SVG 不会被主题重新绘制，必要时另制与主题相配的素材。`caption / annotations / note` 是正文内容，进入原文核对。`PLATE / SEQUENCE / PHOTO_OPEN / MASONRY / CONTACT` 缺实际素材时报错；`ai:编号` 仅在对应成图已经放入 photos 后可用。

### 连续阅读与续页

先按原文的完整段落分配到页，再构建检查。`READING` 不自动分页、不截断段落，也不缩正文。超出容量时把完整段落移到下一页，再核原文及顺序；不能为了变换版式打断同一篇文章。

```yaml
book:
  series:
    essays:
      label: 观察笔记
      items:
        '01': 把看见的写具体
pages:
- layout: READING
  series_header: {series: essays, item: '01'}
  intro: 这一篇的阅读入口。
  text: [第一段完整原文, 第二段完整原文]
  notes: [与本页内容有关的侧记]
- layout: READING
  series_header: {series: essays, item: '01', continuation: true}
  text: [第三段完整原文, 第四段完整原文]
```

首次出现须有首页；孤立续页在完整构建时被拒绝。试排抽样可只取续页，但不能按正式成品导出。栏目和篇名从 `book.series` 读取，中英文可用 `{zh: …, en: …}`；续页自动带“续读 / CONTINUED”。续页可在 `series_header.title` 写本页小题；不覆盖中央篇名。未登记系列的独立页直接使用 `title / kicker`。编辑页修改共用篇名会指向同一个源字段，首页和续页同步重建。

完整例子 `templates/book.editorial.zh.yaml`；双语长文与摄影开场见 `templates/book.reading.yaml`。旧八类版式仍用于快速查阅和原有项目；长文、旁注及多图不必强行改成 `CARDS`。设计与验收见 `references/composition.md`。

摄影布局选型、铺满与出血偏好、功能图例外及跨主题共享原则见 composition.md「跨主题共享的摄影偏好」；完整八页结构样例为 `templates/book.photography.yaml`。
