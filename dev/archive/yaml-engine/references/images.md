# 图片：用户照片 · 资料里自带的图 · 版权与肖像权 · 没有照片 · AI 配图

## 1. 来源、版权与肖像权
- **版权核验**：无论是网上/图库找来的照片，还是从用户提供的 PPT / Word / PDF 中抽取的图片，都必须把来源、作者、许可记进 `images.yaml`（run.sh 每次构建自动生成：每张图用在第几页、原图像素、印出来约多少 dpi、是否做了双色调；`source` / `license` / `credit` 三栏由你填，重跑不会覆盖）。导出自检（`postflight.py`）会列出未填写 `source` 或 `license` 的图片；来源不明、无商用授权的网图严禁默认用于正式出版或印刷。
- **原稿配图与人物肖像权提醒**：用户原稿（如宣讲 PPT）里的配图可能是临时搜来的有版权网图，或包含未成年人/学生正脸。对于对外发放、招生或印刷的手册，必须在第 1 轮沟通合同或交付说明里提醒用户确认**商用图片版权**与**人物肖像权授权**（无授权不露未成年人正脸）。
- **重复与清晰度检查**：构建时提示 `[同图两用]`（同一张照片用在两页）、`[低清]`（低于 150dpi），以及 photos/ 里没用上的图（images.yaml 的 `unused`）。
- **内容不符提醒**：用户给的照片明显和内容不符（如幼儿园手册给的是中学生照片）：照用，但在回复里提醒替换。

## 2. 资料里自带图片（宣讲 PPT、带图的 Word/PDF）
`new_project.sh` 会用 `extract.py` 把图片抽到 `photos/`，并给出：
- `doc.md` 里每页的 `<!-- 第 N 页 · 照片：… · 图形：… -->`（图文对应关系，原文核对会忽略注释）
- `images.md`（尺寸、照片还是图形、建议用法）、`photos/_contact.jpg`（缩略图总览）
- 重复出现的 logo / 装饰和小图标放在 `photos/_assets/`

用法：
- 先看缩略图总览，再定页面清单：图跟着它原来那页的文字走；同时在 `images.yaml` 标记来源为“原稿自带（待确认商用授权）”或用户确认的自有版权。
- **照片**按清晰度用（plan.md 已分好档，阈值只在本节维护）：≥ 2500px 可以满版印刷（FULL、跨页、COLLAGE 大格）；1500–2500px 满版只够电子版，印刷时放进卡片 / 错位 / 组合的图片位或 figure；< 1500px 只做小图。构建时 hb.py 按实际渲染框报 dpi，低于 150dpi 报 `[低清]`。
- **图形**（截图、图表、流程图、插画）放 `figure`（`fit: contain`，截图加 `frame: true`）或 `PLATE` 图版，不放进 COLLAGE、不裁切；PLATE 默认保留完整主体和原色，配合邻近说明（layouts.md §8）。
- 正式logo按品牌包或项目规范完整放置（`logos`块或`figure` + `fit: contain`），保留原件。可选的品牌图形延展按style.md §7.1设计，走独立brand_graphic矢量背景层；仅限用户自有或已获授权的品牌标志，先识别图形符号、字标及组合关系，选择适合作背景的源形，不机械平铺整块logo。
- PPT 的文字多是要点短句：照原样放进 cards / items，不扩写成段落；演讲者备注在 `notes.md`，不是正文，用之前问用户。

摄影铺满、出血、多图与跨页的共享偏好见 composition.md「跨主题共享的摄影偏好」；它适用于当前四主题。图解、标识与二维码继续完整显示。

## 3. 没有照片
先向用户要（活动现场、学校、产品、往届照片都行）。拿不到时：
1. **无图构图**：Swiss、Editorial 或风格派；Swiss 优先靠排印与留白，Editorial 可使用编辑图形，风格派使用自身的结构性几何。气氛底图不能冒充内容插图。
2. **photo 风格 + 占位**：用户想要摄影杂志风、只是照片晚点给 → `image: placeholder` / `img:` 留空，照片到了填文件名重跑。
3. **AI 配图**（见 §4）。
按内容选择图文或纯文字构图。上述自动底纹不适用于 `PLATE / SEQUENCE / PHOTO_OPEN`：这三种布局要求实际内容素材，缺图会报错，不能用气氛底纹代替观察对象或摄影叙事。

## 4. AI 配图
用户素材画风不统一、数量不够、清晰度不够，或用户要求无版权风险的配图时：以用户素材或主题风格为锚点，生成一套画风统一的配图。
1. **定美术方向**：从用户素材里挑一个最能代表品牌的做“锚点”，写进项目的 `ai_images.yaml`：`direction`（全书统一的画风说明）、`style`（每条提示词都带的风格后缀）、`negative`（避免项）、`images`（每个图位：`use` 用途、`tone` 明暗、`ref` 参考素材、`prompt` 提示词）。一张图一个主体，图里不放文字、logo、水印、真实名人或受版权保护的第三方 IP 角色。
2. **版式里先占位**：`image: ai:cover`、`img: ai:lab`、`figure: ai:engine`。`run.sh` 会画出带编号和尺寸的占位图，并按实际尺寸和文字落点生成 `image_brief.md`（每个图位：多大、什么比例、文字压在图的哪块、参考哪张素材、完整提示词）。
3. **生成**：有生图工具（任何内置或已接入的都算）就逐个图位调用，存成 `photos/ai_<编号>.png`；没有就把 `image_brief.md` 交给用户，说明怎么在他们的工具里生成、生成后按文件名放回 `photos/`。
4. **重跑看图**：图到了自动替换占位（不用改 yaml）。主体压到文字、画风跑偏的改提示词重生成；明暗和预期相反时给那页写 `tone: light|dark`。
`PLATE / SEQUENCE / PHOTO_OPEN` 也识别 `ai:编号`，但仅接受 photos 中已经存在的成图，不生成占位。先准备素材，再构建这些页面。
- 不用 AI 重画：品牌吉祥物与 logo、真实的产品界面（必须真截图）、真实的人物和特定受保护场馆。
- AI 图记进 `images.yaml`（`source: AI 生成`，`license: AI 生成 / 无第三方版权`）；用户素材里已有的 AI 生成标识不要擅自去掉。
