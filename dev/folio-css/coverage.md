# Folio 组件覆盖

按阅读任务组织能力，而不是把造型数量当作完整性。所有 HTML 配方在展示页可查看与复制；图表同时提供原始 JSON。

| 阅读任务 | 已有配方 | 设计与数据边界 |
|---|---|---|
| 开篇与阅读 | 标题组、引文、图注、目录、问答、清单、开放表 | 主次由字阶和空间建立；引文不默认使用侧边线加浅色底 |
| 摄影叙事 | 双图、主图与辅图、接触表、错落组图、外侧出血、图文叠放、连续全景 | 裁切、焦点、DPI、图片上的文字对比度须按实际输出验证 |
| 多日行程 | 三日行程、纵向时刻表、比例节奏带 | 等宽日期列表示顺序；时间带每轨15分钟，休息与缓冲显式列出 |
| 时间与协同 | 横向阶段里程碑、并行泳道 | 等距阶段不表示等长时间；泳道为语义表格，尚不是自动甘特图 |
| 经营概览 | KPI与口径、目标/实际/差额、能力证据对照 | 单位、时期、基准、范围和来源不可省略 |
| 定量图表 | 排名条形图、时间趋势、100%或绝对值堆叠、增减瀑布 | 从数据计算，默认包含零轴；比例必须闭合；不自动归一化或隐藏负值 |
| 行业与取舍 | 波特五力、二维决策矩阵、简化价值链 | 五力用于行业结构；定性矩阵不冒充数值坐标；价值链不能凭箭头证明因果 |
| 结论表达 | 结论标题、图表、单位/期间/来源、限制与下一步 | 标题须由数据支持；没有证据时标为问题或假设 |

## 本轮明确没有覆盖

自动甘特与关键路径、地理路线地图、桑基、复杂网络、统计置信区间、双轴图、自动避让的数据散点图尚未提供。它们需要各自的数据语义、几何与验证，不能只换个 CSS 类就宣称支持。

新的版式可以继续组合已有原子。新增图表类型则应先定义数据合同和误导风险，再做生成器、测试与真实 PDF 示例。组件展示中的企业数值均为自拟演示；行程为排版结构示例，未核验场地、交通与天气。

波特五力的方法来源：[Harvard Business School · The Five Forces](https://www.isc.hbs.edu/strategy/business-strategy/Pages/the-five-forces.aspx)。本项目没有冒用咨询公司的品牌或把其名称当作分析准确性的保证。
