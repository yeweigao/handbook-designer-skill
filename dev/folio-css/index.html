字阶、字重与标题字族一起切换

bold 用衬线标题，light 用无衬线标题；两者保留既定的字号与字重阶梯。light 的大字越大越轻，小字保持足够字重。数字与正文同族（Inter），字重跟随字号档位。

一套底座，
从文字到摄影。

  1. 六轨对齐页眉、标题、导语与图注回到同一组轴线。
  2. 大小与轻重字号保持原值；通过真实的字重与标题字族切换语气。
  3. 留白参与构图标题旁的空白保留，短说明落在右侧两轨。
  4. 照片与文字独立摄影进入网格；图注、编号和来源保持可检索的文字。

bold · 白纸

下方布局与组件预览同步切换。配方内明确指定的表面保持原意。屏幕仅等比缩放整张预览，不改书页字号。
