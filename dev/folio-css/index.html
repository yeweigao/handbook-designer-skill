字阶与字重分开

宋体用于展示或连续阅读，黑体用于信息文字，Inter 用于标签与数字。每个字重都对应实际字体文件。

正文 16px，行高 28px；让长段落保持舒适。16 / body
辅助 11px · 图注与页码11 / aux

同一网格，多种比例

六轨是默认参考。长文可以 3+3，正文旁栏可以 4+2；轨道不是六条窄正文栏。

网格组合

节奏有共同刻度

7px 为最小常用间隔，28px 为正文基线。小间距连接信息，大间距划分段落与章节。

fl-gap-3 · fl-mt-5 · fl-py-2

比例、裁切与焦点独立；原图保持不变。
