# 从书页回到共享能力

同一套 Folio CSS，按两种出版任务组织实例。页面专属 CSS 决定本刊构图，不藏成万能模板。

| 样册与页面 | 共享能力 | 本书的编辑选择 |
|---|---|---|
| 看见之间 1 | bleed、inverse、scrim、display字阶 | 星空暗部落标题；保留人物与望远镜 |
| 2–3 | 六轨偏置、阅读宋体、数字字阶、方形图框 | 编者说明与索引分工 |
| 4–5 | 4+2主旁栏、真实400字重、1.5阅读行距、连续双栏 | 长文、引语、照片形成密度变化 |
| 6–7 | panorama共享坐标、非零出血补偿 | 银河图高203mm；书脊区域不放精读信息 |
| 8–9 | rows/span、frame-fill、比例与focus | 同源图像不同取景，显式行列起点 |
| 10–11 | 二维模块组图、镜像外侧出血 | 左页多图与右页整高主图形成面对页关系 |
| 12–13 | chronology、字阶、开放表格 | 方法说明与证据区分 |
| 14–16 | dark/accent颜色角色、错位网格、图像索引 | 纯字收束、来源与封底 |
| 从判断到行动 1–4 | KPI、趋势、结构、瀑布、排名、目标表 | 同一组经营示例数字，单位与口径一致 |
| 5–6 | 五力、定性矩阵、能力证据表 | 有证据的主张与尚待验证的问题分开 |
| 7–9 | 多日行程、比例节奏带、纵向timeline、泳道、里程碑 | 活动、休息、缓冲与阶段进入条件共同可见 |

原始数据见 `chart-examples.json`；复制配方见展示中的组件详情。更多边界见 [coverage.md](coverage.md)。
