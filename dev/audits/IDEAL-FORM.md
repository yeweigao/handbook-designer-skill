# handbook-designer 理想形态

> 写作时间：2026-10-21 · 定位：**未来所有迭代的参照系**（north star）。
> 本文不列任务、不分阶段——任务与验收在 `STRUCTURE-FREEDOM-2026-10-21.md`；本文只回答一件事：**这个 skill 应该长成什么样子**。
> 判断标准：以后每次改 skill，先问一句「这次改动是让它更接近本文，还是更远」。

---

## 0. 一句话定义

一台**会提主张的印刷设计伙伴**：判断显式、测量冷酷、经验可积累。

- 它不说「我按规矩排好了」，它说「这一本，我判断该这样排，因为___」。
- 它不把「过了门禁」当成绩，门禁只是地板。
- 它每做一本都比上一本多一点经验，这些经验留在仓库里，而不是留在某次对话里。

## 1. 它要解决的真实问题

20 本样册的实验结论必须写在最前面：**覆盖率和硬伤检查很可靠，但它证明的是「规则被执行了」，不等于「设计判断发生了」。**

失败模式不是「排得丑」，而是**目标置换**：流程越长、版式名字越多，模型越容易把「选一个 layout、过 GATE」当成目标，忘了先问「这一页到底要让读者做什么」。于是稳定地产出**正确但越来越像**的册子。

所以理想形态的第一性质**不是「更自由」，而是「让判断成为必经之路，且留痕极短」**。自由是结果，不是目的。

## 2. 三层宪法

| 层 | 内容 | 规则 |
|---|---|---|
| **硬约束** | 网格、印刷安全（4 的倍数/出血/字号档/dpi/装订）、事实出处（facts）、图片授权、原文保真（MISSING/ORDER/EXTRA） | **不可破**。破即停，不讨论。 |
| **默认策略** | 主题、配色、版式、页序节奏、纸面轮换 | **可以偏离**，但必须在 `page-plan.md` 写一行：**偏离什么 · 为什么 · 代价**（对 QA、印刷、审稿的影响）。 |
| **创作空间** | 内容块与组合规则、发明新版式 | **鼓励发明**，不用只在命名版式里选。发明仍过全部硬约束测量，且必须留痕、可复制。 |

### 偏离的心理成本必须低
一行字，不是审批表。偏离是**默认允许**的常规行为，不是例外程序。
写成表格、要求填七八栏，模型就会绕开它——绕开的那部分判断就重新变回暗箱。

### 判断的留痕有额度
整册的判断留痕（概念句 + 指纹理由 + 逐页 claim + 偏离/发明行）**不超过一页 A4**。
超过这个额度，说明在写汇报，不是在设计。

## 3. 模型侧的理想工作循环

目标：**十分钟内完成，不是仪式**。顺序不可省，每一步只写一句话。

1. **盘点**——不是统计字数，是列出「只有这份原文才有的东西」：独特事实、数字、约束、材料、仪式、印刷物。这是结构与图片的唯一来源。
2. **一句话主张（概念句）**
   > 这一本，**[只有这份原文有的东西]** 成为 **[结构设备]**。
   过**竞品测试**：把同类机构填进句子，若照样成立 → 这是品类默认，重写。「干净大气」不是主张。
3. **发牌选指纹**——从结构库发 3 个候选（封面语言/章节处理/图文策略/阅读入口/装饰系统/节奏型），**自动避开同系列最近用过的组合**。选一个，写一句「它为什么能承载主张」。不允许「都行」。
4. **逐页 claim**——一行：「这一页要让读者 ___，用 [原文证据] 证明」。没有 claim 的页删掉。
5. **蓝图三选一**——目录选（已验证 token）/ 原语组合 / 发明（一行理由）。
6. **落版 → 测量 → 看图 → 改**——有界：最多三轮。

防退化的设计：**判断发生在第一步到第五步的纸上，不是发生在 yaml 里。** yaml 只是把已经想清楚的事写下来。

## 4. 引擎侧：从「排版器」变「量尺」

- **token 是已验证的模式库，不是菜单**。每个带适用内容形状、最小示例、反例提示；开头明写「这是例子，不是围墙」。
- **原语开放组合**：网格跨度 + 文字栈 + 吸收体，可以拼出目录里没有的页面。
- **测量覆盖发明结构**：检查是几何级与内容级，不依赖 token 名——模型发明的东西同样要过溢出、重叠、对比度、空屏、相似度、内容量匹配。
- **门禁分两级**：硬伤拦构建；提示只报告。**GATE PASS = 可交付，≠ 好。**
- **新检查的价值观**：让「薄」和「撞形」可测量地失败（空屏入罪、相邻结构相似度、短文案配阅读式版面的提示），而不是靠审稿人的心情。

## 5. 基因层：受控词汇表（自建，不用 Tailwind）

**结论：自己写一套词汇表，但抄 Tailwind 的三条纪律，不接它的运行时。**

理由一句话：**Tailwind 解决「写 CSS 太慢」，我们解决「印刷几何必须精确且可测」。**
网格尺寸从字号推导（16px → 栏 80 / 行 28），所有边吸到整行、整栏、字号档；rem 间距档与任意值（`w-[80px]`）都不解决这个问题。单文件离线交付也不允许 CDN 或 Node 构建步（多一层版本漂移）。

**借它的三条纪律**：
1. **所有值只取档位**——我们更严：吸到整行 / 整栏 / 字号档，不写裸 px。
2. **token 单一来源**——已经做到：Python 每次构建注入 CSS 变量（`--bs/--lh/--gut/--fg/--hd/--acc…`）。
3. **组合优于新增**——能用已有原语拼出来的，不许新写类。

**四层结构**：

| 层 | 内容 | 可变性 |
|---|---|---|
| **基因（不可变）** | 6 栏网格 · 行线 28px / 整字规则 · 字号档 13·16·23·33·47·56·80·112·160 · 两套字重阶梯（bold/light）· 8 个颜色角色（`--fg/--hd/--acc/--num/--lab/--mut/--rule/--line`）· 底（纸 / A / B / 照片）· 两档线（2px 粗 / 1px 细）· 间距倍数（m1/m2/m3 = 1/2/3 行） | 一组书共用；改了就是另一族 |
| **组件（约 25 个原语）** | 文字栈、段落、标题档、展示字、导语、标签、图注、数字、粗线/细线、图、图版、网格、卡片、旁注、表格行、轴行、清单、引用、填写线、色块、页眉页脚 | 只增不减；增要过维护轮 |
| **语法（自由度所在）** | 栏跨度 1–6 · 栈的位置（上沿/下沿/跟随）· 吸收体（照片/色块吃掉剩余空间）· 节奏（底轮换/镜像/密度） | **自由组合** |
| **惯用法（32 个 token）** | FULL / ONE / TWO / STEPS / TABLE / RHYTHM / PLATE… = 语法的高频组合 | 参考，不是菜单 |

**基因一致性就是这么来的**：自由组合只能改**语法**，不能改**基因**。所以两本书可以结构完全不同，但字号档、颜色角色、线宽、行线是同一套——一眼看是同族。

**必须防的陷阱**：组件层不许升到复合高度。「卡片区」「图版页」这类复合组件一出现，就又变回菜单——那正是现在的问题。**词汇表只到原语级，组合留给人/模型。**

**改造动作**：
- 139 个类归并为 **~25 个原语 + ~30 个组合工具类**（`span-1..6` / `rows-N` / `stack-top|bottom|follow` / `tone-paper|A|B`）——工具类就是 COMPOSE 模式的 CSS 表达
- 一次性类（`.cn-geo-field` 这类）升格或删除；历史遗留层（`.a/.os/.sf`）清掉
- 产出 `references/primitives.md`（每项：yaml 写法 + CSS 类 + 印刷行为 + 反例）
- 产出 `dev/gallery` 的**基因样张**（字号档、颜色角色、两档线、各原语实物）——改了 CSS，漂移一眼可见

## 6. 经验层：skill 会生长

**三本账，互不覆盖：**
- `brief.md`——用户授权（人决定的方向）
- `page-plan.md`——模型判断（含偏离与发明的一行理由）
- `proposals.md`——模型创新（每次超纲决定 + 效果）

**复盘闭环：**
每次偏离、返工、审稿失败 → 记回项目与 `dev/audits` → 维护轮周期性汇总：
- 重复出现的模式（两次独立出现）→ **晋升**进结构库，带证据链接
- 被视觉审稿推翻的决定 → 写进**已知陷阱**
- 每条结构库条目都**可追溯**：能追到把它带进世界的那次使用

**这是理想形态最重要的性质**：目录是长出来的，不是写出来的。skill 通过使用变强，而不是靠人改 py。

## 7. 人的位置

- 人选**方向**与**验收**，永远不碰 token 与 px。
- 第 2 轮样张 = **三结构方向**（同一内容三种指纹预览），不是三配色。
- 交付时**披露纪律**：偏离清单 + 代价、待复核事实、版权与印刷提示，一次说清。

## 8. 质量观：重新定义「好」

| | 旧标准（现状） | 理想标准 |
|---|---|---|
| 通过 | GATE PASS | GATE PASS + 每页 claim 兑现 |
| 好 | 无硬伤、有起伏 | 读者翻开 5 秒能说出「这是什么/给谁/做什么」；整册有自己的结构语言；两本之间不像 |
| 审稿 | 查违规 | 查**主张是否兑现**（page-plan 说的事，成品里做到了吗） |
| 一致性 | 同类必同构 | 同类**不许**同构；一致性在品牌与基线，多样性在结构 |

## 9. 诚实的代价

- **自由度 ↑ → QA、审稿、交付成本 ↑**。对冲：测量扩展 + 提示分级 + quick 全自决+披露。
- **判断留痕 ↑ → 流程变长风险**（这正是要防的病）。对冲：一行制、额度制、模板化——宁可少记一条，不可多填一栏。
- **目录生长 → 质量漂移风险**。对冲：晋升需证据（两个独立项目 + 审稿结论）；反例必须入陷阱库。
- **发明自由 → 不可控美学**。对冲：发明必须回答「它服务哪个读者任务」，回答不了就是为不同而不同，作废。
- **词汇表收敛 → 一次性成本**。139 类归并会碰到历史样式（`.a/.os/.sf`），要做回归；但这是「自由组合有参考」的前提，不做则词汇表名存实亡。

## 10. 反目标（它不该变成什么）

- ❌ **更多版式的菜单**——换皮自由不是结构自由。
- ❌ **全自动无人值守的设计工厂**——付费客户要的是确认环；过程透明比速度值钱。
- ❌ **审美独裁**——用 house style 禁这禁那（禁细线、禁编号、禁等宽），与印刷网格的本性冲突。
- ❌ **流程宗教**——把判断变成仪式，把留痕变成报表。
- ❌ **引擎替代设计**——测量能证明「不难看」，永远证明不了「该长这样」。
- ❌ **接一个 CSS 框架**——框架解决打字速度，不解决印刷几何；纪律可以抄，运行时不要。

## 11. 怎么知道达成了（验收）

1. **多样性**：同一份原文连跑 3 次，3 个指纹六维 ≥3 维不同，全部 GATE PASS，逐页目检合格。
2. **判断在场**：3 次的概念句互不相同且过竞品测试；三本账齐全。
3. **发明可行**：能发明出一个目录里没有的结构，并通过全部测量。
4. **进化在迹**：proposals 有真实记录；至少一个模式被识别为晋升候选。
5. **贯彻度可审**：指纹贯彻度检查在 ≥2 个项目留下记录。
6. **基因收敛**：139 类 → ~25 原语 + ~30 工具类；`references/primitives.md` 与基因样张存在，样式漂移可见。
7. **不回退**：selftest 全绿；旧样例可重建。

## 12. 与外部参照的关系

- **Hallmark** 证明：结构多样性是反 slop 的主轴 → 已吸收为指纹+发牌+避让。
- **taste-skill** 证明：强制理由（发牌+概念句+竞品测试）与「薄要可测量地失败」是让模型思考的两根杠杆 → 已吸收；其素材管线归 research 路线；其无人值守与审美独裁**不采纳**。
- **Tailwind** 证明：档位化、单一 token 来源、禁止任意值是让生成结果不散架的三条纪律 → **借纪律，不接运行时**（见 §5）。
- **我们独有且必须保住**：原文保真三项、印刷生产链、三本账 + 人工确认环。

## 13. 一页速查（给未来的模型）

1. 先问「这一页要让读者做什么」，再问「用哪个版式」。
2. 概念句过不了竞品测试，就别开始排。
3. 偏离是常态，写一行理由和代价即可；不许沉默偏离。
4. 发明可以，但要能回答「它服务哪个读者任务」。
5. 组合只能改语法，不能改基因（字号档/颜色角色/线宽/行线）。
6. GATE PASS 是地板；判断有没有发生，看三本账，不看构建日志。
