## 0. 总纲：判断还模型，测量留引擎，skill 通过使用进化

| 层 | 内容 | 归属 | 终态 |
|---|---|---|---|
| **判断层** | 什么结构配什么内容、什么节奏、怎么开场、图文策略 | **模型**（艺术指导） | 从代码/枚举收回，变为显式、可追溯、须论证的判断 |
| **测量层** | 栏宽、行线、字宽度量、溢出/重叠/对比度/空屏/结构相似度 | **引擎**（量尺） | 保留并扩展——**能测模型发明的任何结构** |
| **进化层** | 新模式的出现、验证、晋升 | **使用过程本身** | proposals 日志 → 维护轮 → 参考目录；目录是长出来的，不是写出来的 |

三句话架构：**token 从菜单变积木（原语开放组合）；每次超纲判断必须留理由（可追溯）；重复出现的模式晋升进目录（skill 越用越强）。**

不能动的是命，不是限制：印刷算术（6 栏网格/字号档/出血/dpi）、原文保真三项（MISSING/ORDER/EXTRA）、facts、人工确认环。**gate 的存在正是让模型敢思考的安全网——没有测量的自由等于上午那堆字体度量事故。**

## 1. 诊断与实证（分阶段版结论的压缩保留）

**锁在四层**：哲学层（SKILL.md 纪律组合导向统一）· 流程层（同 kind 页序同构）· 资产层（8 token 菜单，文档滞后于引擎 32 token）· 检查层（lint 封面规则锁死封面语言）。

**实证（structure-demo/，两轮）**：B（一次换结构+主题+图）被用户判「不好看」——根因是三者错配 + 短文案撑不起阅读式版面，**保留为反例教材**（free_v1）。C（只换结构，同 swiss×mono 同文案：TYPOGRAPHIC→TWO→STEPS→TABLE）GATE PASS 全 0、目检合格、与 A 完全不像——**结构自由成立**（struct_v1 vs now_v1）。设计铁律：结构必须匹配内容量；换结构不许捎带换主题/图片。

**外部对标结论**：Hallmark（纯 prompt 规则集）与 taste-skill（发牌脚本+概念句+素材管线+浏览器 inspector 的重装版）证明两件事——反同质化靠**强制理由**（随机发牌+竞品测试）而非枚举轮换；「薄」要**可测量地失败**（空屏入罪）。**偷机制，不偷审美**（它的禁细线/编号 house style 与印刷网格本性冲突）。三家之中我们独有：原文保真体系、印刷生产链、人工确认环。

## 2. 终态架构（六层）

### 2.1 入口层：SKILL.md 从「规章」变「聘书」

- description 重写：从「将材料做成手册」变为「杂志级手册的艺术指导伙伴」——触发词保留（小册子/把 PPT 改成手册/排高级点），新增设计意图类触发（「这期想换个样子」「不想再跟上次一样」）。
- 正文三段：**哲学**（判断/测量分工，§0）· **路线**（8 条，§4）· **纪律三层分类**（基线锁死 / 参考降权 / 自由区授权，§3）。
- 工作语言全文替换：「只选版式、放原文，不写尺寸」→「**先判断结构，再从目录选、用原语组合、或发明新结构；超出目录的，在 page-plan 写理由**」。尺寸纪律保留（那是测量层的事）。

### 2.2 判断层：模型的新工作方式（六步，全部显式留痕）

```
读原文盘点 → 概念句 → 沟通合同+发指纹 → 逐页论证 → 结构蓝图 → 落版测量
```

1. **盘点（inventory）**：除字数/照片分档外，新增「只有这份原文才有的东西」清单——独特事实、数字、约束、材料、仪式、印刷物。这份清单是结构与图片的唯一来源（ borrowed from taste-skill，adapted for print）。
2. **概念句（idea sentence）**：每本书开排前必须填——
   > **这一本，[只有这份原文有的东西] 成为 [结构设备]。**
   配**竞品测试**：把同类机构填进句子，若照样成立 → 品类默认，作废重写。「干净大气」不是概念。概念句进 `brief.md`，**lock.py 无概念句拦构建**。
3. **发牌选指纹（dealt fingerprint）**：`python3 hb/fingerprints.py deal <项目> [--series <系列名>]` 从结构库发 3 个候选指纹（六维组合：封面语言/章节处理/图文策略/阅读入口/装饰系统/节奏型），**自动避开同系列最近用过的组合**（反同质化）。模型必须选一个并写一句「这个指纹为什么能承载概念句」；换发仅限可陈述的理由（与品牌冲突/素材不存在），记录进 proposals。不允许「都行」。
4. **逐页论证（claims with proof）**：每页一行「这一页要让读者 ___，用 [原文证据] 证明」。没有 claim 的页删掉——从机制上消灭「为排版而排版」和 hero-logos-三特性-页脚 的股票序列。
5. **结构蓝图（page-plan 升级）**：指纹 + 概念句 + 逐页 claim → 每页版式决策三选一：**目录选**（32 个已验证 token）/ **原语组合**（COMPOSE）/ **发明**（写理由，进 proposals）。蓝图阶段显式检查**内容量-结构匹配**（短文案禁阅读式版面——Demo B 铁律，入 lint）。
6. **落版测量**：进 §2.4。

**三本账分离**（终态核心机制）：`brief.md` = 用户授权（人决定的方向）· `page-plan.md` = 模型判断（含理由）· `proposals.md` = 模型创新（超纲决定+效果）。三者互不覆盖，视觉审稿逐本核对。

### 2.3 积木层：token 从菜单变积木

- **32 个已有 token 全部保留为捷径**，但文档定位从「标准模式」改为「已验证的结构模式」——每个带适用内容形状 + 最小 yaml 示例 + 「这是例子不是围墙」声明。
- **新增原语组合模式（COMPOSE）**：yaml 可直接声明网格跨度 + 文字栈 + 吸收体：
  ```yaml
  - layout: COMPOSE
    cells: [{span: [1,2], role: text, stack: top}, {span: [3,6], role: photo, rows: 12}]
    idea: 把机构的七扇门排成一条书脊线   # 这一页为什么长这样
  ```
  引擎把 COMPOSE 页与 token 页**同尺度测量**（fill.js/doctor 几何与 token 无关——测量层天然覆盖发明结构）。
- **发明即提议**：COMPOSE 中无法用既有原语表达的结构，进 proposals 等待晋升；连续两次独立出现的相同发明 → 维护轮升级为新 token 候选。

### 2.4 测量层：gate 扩展为「万能测量」

保留：溢出/重叠/对比度/MISSING/ORDER/EXTRA/facts/dpi/出血（硬伤级不动）。
新增（全部几何或内容级，**不依赖 token 名**，故可测任何发明结构）：

| 检查 | 内容 | 级别 |
|---|---|---|
| 概念句在席 | brief 无 idea → 拦 | 硬伤（lock） |
| 空屏率 | 单页内容占比过低；整册节奏曲线无起伏 | 提示（已有 [留白] 扩展到结构级） |
| 相邻结构相似度 | 连续两页同版式同构图 → 提示（mirror 自动换之上，扩展到指纹级） | 提示 |
| 内容量-结构匹配 | 短文案（<N 字/页）配阅读式版面 → 提示 | 提示（Demo B 铁律入规） |
| 指纹贯彻度 | 每页 job 与 brief 声明的六维指纹对照，偏离无说明 → 提示 | 提示（visual-review 核） |
| 封面语言松绑 | lint 不再要求封面必须是 FULL/POSTER/PHOTO_OPEN——TYPOGRAPHIC/COMPOSE 等可以是封面（当前是「围墙」实证） | 规则修改 |
| proposals 在迹 | 蓝图声明了超纲但 proposals 无记录 → 提示 | 提示 |

### 2.5 进化层：skill 通过使用变强

- **proposals.md**（每项目一份，格式模板进 templates/）：日期 · 超纲决定 · 理由 · 类型（新指纹/新组合/新 token 候选/规则偏离）· 效果（GATE 结果 + 视觉审稿结论）。
- **维护轮**（人或维护 agent，触发条件：累计 N 条 proposals / 用户要求）：读全部 proposals → **重复出现的模式晋升进 references 结构库**（带证据链接）；被视觉审稿推翻的决定 → 写进「已知陷阱」；晋升记录进 dev/audits。
- **结构账本**：每本书的指纹记入项目级 ledger；发牌时读取以避免同系列撞形。
- 终态检验：**references/layouts.md 是一份活目录**——每条目可追溯到把它带进世界的那次使用。

### 2.6 人工确认环：从「选配色」到「选方向」

- 第 1 轮沟通合同不变（读者/场景/读完做什么/必须/不能）。
- 第 2 轮样张升级：`directions.py` 从「三配色方向」改为「**三结构方向**」——同一内容三种指纹的封面+内容页预览。人选方向，**永不碰 token 与 px**。
- 16 页以上试排不变；quick 路线全部自决但回复开头必须列出「我替你做的主张」——含概念句与指纹选择理由。

## 4. 工作流终态（9 条全部重写）

| 工作流 | 终态 |
|---|---|
| **new** | 建项目 → 盘点（+主体清单）→ **概念句** → 第 1 轮沟通合同 → **发指纹 + 三结构样张** → brief（含 idea/fingerprint）→ 逐页 claim → 蓝图（选/组合/发明）→ （≥16 页）试排 → 全本 → 视觉审稿（含指纹贯彻度+陌生读者 5 秒测试）→ 导出 |
| **quick** | 同链全程自决；披露清单新增概念句与指纹理由；仍走全部测量 |
| **beautify** | 内容冻结（frozen 纪律不动），**结构在测量边界内自由重组**；页序变化逐页对应记 brief |
| **reuse** | 拆二：`reuse-asset`（默认）继承品牌/字体/图片资产，**结构必须新**（发牌避让上一本）；`reuse-structure` 仅用户明说「和上期一样」时走，brief 记 inherit + 授权 |
| **revise** | 反馈表新增「结构级」行：换页序/换版式策略 → 回蓝图改 → 重排受影响页 → 连带复核 |
| **brand** | 品牌包加可选 `structure:` 倾向字段（封面语言/装饰系统/版式偏好），参考不强制；老包无字段正常降级 |
| **research** | facts.md 之外 + **素材发现管线**：按主体清单检索开放图库（CC0/CC BY），下载即记 source/license 进 images.yaml，署名行自动生成；无网络时明示 |
| **edit-online** | 保持（在线改字/换图/同步）；结构预览列为后续候选 |
| **visual-review** | 审稿表新增：指纹贯彻度、陌生读者 5 秒测试（翻开封面 5 秒能说出这是什么/给谁看/做什么）、proposals 结论核对 |

## 7. 验收口径（终态）

1. **多样性**：同一 doc.md 连跑 3 次 new，3 个指纹六维 ≥3 维差异，全部 GATE PASS、逐页目检合格。
2. **判断在场**：3 次运行的概念句互不相同且通过竞品测试；brief/page-plan/proposals 三本账齐全。
3. **发明可行**：模型能用 COMPOSE 发明至少一个新结构，通过全部测量（含新检查），并留下 proposals 记录。
4. **进化在迹**：proposals 日志有真实记录；至少一个模式被识别为晋升候选并写进维护记录。
5. **贯彻度可审**：visual-review 的指纹贯彻度检查在 ≥2 个实测项目留记录。
6. **不回退**：完整 selftest PASS；dev/gallery 样张与模板样例重建不回退；skill-product_v1 迁移到新配色后可重建（klein/clash 已停用，见 audits 记录）。

## 8. 风险与对冲

| 风险 | 对冲 |
|---|---|
| 判断放开 → 质量方差变大 | 测量层扩展（空屏/相似度/匹配/贯彻度全部入检）+ 视觉审稿环 + 陌生读者测试 |
| 概念句变八股 | 竞品测试 + 维护轮淘汰空洞概念进「已知陷阱」 |
| 发牌变成新围墙 | 换发仅限可陈述理由且必须记录；proposals 复盘时审计「舒适区漂移」 |
| COMPOSE 复杂度 | 32 token 全留为捷径；COMPOSE 是进阶通道不是默认路径 |
| 人工环成本 | quick 路线全自决+披露；三结构样张替代三配色样张（成本平移） |
| 素材管线版权 | 只走许可分级白名单；下载即落 source/license；无网络明示降级 |
