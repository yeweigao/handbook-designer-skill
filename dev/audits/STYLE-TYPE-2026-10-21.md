# 第三轮 · 五主题、共享排印与 Editorial 收敛

本轮按用户反馈做减法。目标是减少不稳定的皮肤选择，统一字体和排印，把 Editorial 的书卷感落实到真实页面。HTML / CSS Grid 与内容版式继续共用一个引擎，不改用 SVG 绘制正文。

## 已实现

- 当前五主题：Photo、Swiss Minimal、Editorial、风格派、孟菲斯。后两种按用户后续要求恢复；notebook / inkwash / papercut / riso / aurora / nebula 退出注册，旧效果图归入 `dev/archive/retired-styles/`。
- `book.typography: bold / light` 独立于主题与字体家族，五主题均可采用。bold 大标题厚重；light 大字轻、小字稳，正文和小字至少400。标题自动缩小时按实际字号重算，避免先定字重、缩完字号却保留细字。
- 默认中英文仅用思源黑体 / 思源宋体。Photo、风格派为宋体标题与黑体正文；Swiss、孟菲斯用黑体；Editorial 标题与正文用宋体，标签和页码用黑体。Inter 等只在明确配置时加载。
- 200 / 250 / 300 使用真实静态字形，不用浏览器合成。屏幕、普通PDF及可编辑PDF入口共用配置；本轮成品只导出普通PDF，未另行制作全字库可编辑PDF。
- Swiss 使用中性纸面、墨字和一个强调色，移除大圆装饰、渐变及撞色入口。风格派、孟菲斯保留各自明确的图形与颜色角色。
- Editorial 参考用户指定的 Monocle 式克制：暖纸 `#FDFCF3`、宋体阅读、短简报三栏、中小幅矩形图片与细线；不自动加装饰环或戏剧化开篇。长文使用已有 READING，不把整篇文章硬塞进三栏。
- `templates/book.editorial.zh.yaml` 重写为八页克制的栏目样例，原第一轮模板保存在 `dev/archive/editorial-v1/`。规划脚本和品牌工作流同步清理旧皮肤与撞色推荐。

## 首轮失败与修正

1. 风格派 STAGGER 第三行出现晚到字体引起的裁切。初始 `document.fonts.ready` 没有预载动态请求的新字重，首次量高后字形替换造成重新换行，保存的旧QA却没有反映变化。现在在排版前加载本书全部注册字重，生成风格派页脚后再应用排印并重核QA。原输入重测 GATE PASS，实际 PDF 的第三行完整。
2. 照片回归仍断言默认数字必须为 Inter，在用户要求统一思源后失败。改为核实际的新默认字体，保留显式 Playfair 扩展测试。
3. 新排印比较图尚未生成时文档引用检查失败；生成实际 PDF 对照图后补齐。本轮保留这些失败日志，没有用最后的截图覆盖问题记录。
4. 最后逐份核PDF字体表时，发现原创叶片图的三个数字还用了Georgia。将它们改为真实思源黑体500轮廓，保留SVG语义说明与编号，不改变图形或图文几何；重导受影响五份样册并复核字体表。
5. 图注之后接小标签时，原文检查器把两者拼成一行而误报 EXTRA；增加 figcaption 换行边界及反例测试，未修改原文去迎合检查。

## 范围与下一步

这是实现与样张的收敛，不代表所有手册的视觉质量已经解决。短文样张部分页留白较多，不能据此推断300页杂志的密度策略。真实长手册仍需按内容控制篇幅、图片、栏目和阅读节奏；同事件摄影叙事、复杂语义插图及普通入口的独立执行评测沿用 ROADMAP 的待办。三栏是可选组合，不做全局强制；Monocle 参考也不复刻刊头或宣称是其官方模板。
