# Folio 的瑞士主义底座

Folio 把网格、排印、留白、比例、信息层级和摄影统一为一种构图方法。文字册、摄影册、企业画册、行程与图表共用这一底座；`bold` / `light` 是同一套系统的排印选择。默认颜色与可组合能力见 [Folio CSS](../families/folio/README.md)，字体与冻结规则见 [style](style.md)。

## 先决定关系，再选配方

每页先写清四件事：读者要得到什么；第一眼看什么；沿哪条对齐线继续读；哪一块空间留给停顿或照片。用真实内容确定栏宽与图片比例，再选布局或写页面 CSS。展示页提供组合材料，不能把展示中的页坐标、英文副标题和装饰一起套进新册。

| 基础 | 作者动作 | 最终页面中观察 |
|---|---|---|
| 网格 | 从六栏 / 十二栏细分起步，给标题、正文、图片、图注安排共享起点；把相关元素合为组 | 看不见辅助线时，边界与阅读路径仍有秩序 |
| 左齐右松 | 连续阅读文本默认左对齐、右侧自然换行；短标题按语义断行 | 没有为了填满行宽而拉开的字距；标题末行不剩无意义单字 |
| 不对称 | 用大小、位置和空白分配视觉重量；主内容可以占多栏，注释留窄栏 | 焦点明确，小信息可查，画面不靠每块等大来维持稳定 |
| 字阶 | 选主标题、正文与必要的辅助层级；使用对应的字重，先解决行长再缩字 | 主次一眼可辨；小字在印刷尺度仍可读 |
| 留白与节奏 | 让组内间距小于组间间距；复用节奏单位，给章节转换保留停顿 | 空白能分组或定焦；密集页也没有连成一块的文字墙 |
| 颜色 | 以纸、墨和一个强调色起步；用强调色标重点、状态或路径 | 强调色有稳定含义；删去色块后仍能读懂结构 |
| 摄影 | 根据主体、方向、证据作用与裁切空间决定满版、局部出血、网格内单图或序列 | 图像承担叙事；图注能追到对应照片；关键主体完整 |
| 功能性图形 | 线条用于分隔、对齐、坐标或连接；标记用于导航、索引或真实数据 | 每条线、每个数字都能说明作用，标尺与数据可信 |

六栏、栏距和节奏值是 Folio 的起点。不同纸张、语言、装订与读者可以改变它们，理由记入 brief，并在困难页和面对页中检验。网格有意偏移时，其他对齐关系仍须支持阅读。

## 表现力从比例和材料中来

- **文字主导**：大标题与小号注释形成尺度反差；正文保留稳定行长。巨字可以作为真实标题，也可以是重复的装饰；按实际内容作用标记，不能把唯一信息改为 `deco` 来逃避检查。
- **摄影主导**：照片可占满整页、跨页或部分版面；标题和图注继续沿用相同的网格、排印与颜色角色。白边照片、细节图和连续组图同样成立。摄影不需要另一套家族。
- **证据主导**：一个主结论配可核实的数据、图表或案例。保留口径、时期、单位和来源；用直接标注、共同坐标和强调序列组织阅读，避免每个数字都变成独立卡片。
- **程序与变奏**：可用重复、序列、巨字、反白、色面、旋转或图文叠放表达材料；先决定表达什么，再选择手法。阅读文字保持可读，出血与局部叠放按契约声明，最终检查实际 PDF。

红黑白是可用的配色起点，品牌色可以替换强调色；照片允许保留自然颜色。定量图表需要多序列时，可以使用有含义的辅助色与线型，并明确图例。没有每页一个红点、必须黑白照片、固定插一张满版图的数量规定。

## 全册的统一与变化

让栏目、索引、图注、表格口径和续页关系稳定；让内容密度、图文比例、主次尺度及留白位置随阅读任务变化。先试正文密集页、摄影页与数据/行程页，再检查开场和收尾。统一不靠每页重复横线、浅色底块或同一标题位置；变化也不要求每页换布局。

最终在缩略图、面对页和单页阅读尺度分别审阅。若全册只剩红黑白与大字、正文靠缩小字号塞满，或每页都像同一张卡片的重排，回到材料和阅读路径重做。详细判断见 [review](review.md)。

## 如何使用完整展示与样刊

[系统展示](../dev/folio-css/index.html) 与配套样刊按 API 分组、布局、组件和表现手法提供可查看的组合示例。这里的完整覆盖指这些公开能力都有归属和示例，不代表穷举所有原子排列、内容长度、纸型及品牌覆盖。浏览器回归证明被测组合的实际排印、颜色与几何；一册新内容仍须经过最终 PDF 的技术检查和逐页审稿。
