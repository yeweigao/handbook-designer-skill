# 构图与整册节奏

从材料、阅读任务与视觉主张推导页面。HTML/CSS/SVG 是自由创作空间，家族基因维护同册秩序；没有整页布局注册表。

## 三个尺度

- **整册**：开场让人理解主题与读法；正文展开证据；查阅区稳定；末尾给实际行动。章节转换和呼吸页要有内容依据，不按固定间隔插大图或换底色。
- **页面/跨页**：先定读者第一眼看什么、下一步读哪里。照片、摘句、数据或正文都能当主角。短稿允许留白，密集页依靠层级和分组；不为平均空白率塞装饰。
- **信息组**：标签和值、数字和单位、任务和产出、图和图注保持关系。普通长文可续排，日期/联系人等查阅信息用完整组，不能只因累计字数多就分栏。

## CSS 的责任

`design.css` 固定颜色角色、字体角色、字号层级、间距、线条与低层原语；`book.css` 表达本书构图，语言覆盖写 `lang/<lang>.css`。Campus 的六栏与 28px 基线是家族默认，不是普遍约束。普通 Grid、Flex、定位与局部尺寸都可使用；有理由改变家族级决定就记录并看全册。

完整页面作为可读示例保存，不进入家族模板菜单。可以延续同系列结构，也可以为新内容调整；不强制每页都不同，不以类名或相邻页相似度评优秀。

## 照片与跨页

真实主图先看主体、方向、背景安静区及裁切余量，再决定字落纸面还是图上。要贴边时明确定义出血，不把正文行长也铺满。图解、地图、logo 等保留完整信息，不为了铺满裁掉。

跨页是两张物理页的联合构图：同一 `data-spread`、正确左右位置、图像坐标连续、关键主体和文字避中缝。封面是独立右页时，第一组面对页通常为 2–3。加删页必须重查跨页、页码、目录与装订，不能并排两张独立页就称为联合跨页。

正文、密集页、无图页和最弱页同样要完成设计。最终判断见 [review](review.md)，作者标记及物理约束见 [contract](contract.md)。
