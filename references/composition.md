# 统一网格上的编辑变奏

用于新册规划、旧册改版或“整本太像模板”的反馈。先读内容，再选择构图；不要求每本使用全部变奏。参数由 layouts.md 管，主题由 style.md 管。

## 分层与职责

| 层 | 决定什么 | 不决定什么 |
|---|---|---|
| Grid 网格 | 画幅、版心、六条对齐轨道、基线与字号档 | 每页必须分成六栏正文 |
| Layout 版式 | 轨道如何合并、阅读顺序、图文比例、旁注归属、跨栏与错位 | 固定品牌色、特定字体、示例照片 |
| Theme 主题 | 色彩角色、线条、图像处理与局部质感 | 改写正文流向、每页另造坐标系统 |
| Typography 排印 | 共享的字号／字重阶梯与实际字体角色 | 因主题不同另造一份同义阶梯 |
| Brand 品牌 | 真实标识、身份色、字体要求、经过核对的品牌母形 | 无依据的象征含义 |
| Project 项目 | 实际内容、图片、页序、主次、每页阅读速度 | 用缺乏内容依据的装饰填空 |

配置分工：`book.style / colors` 管视觉主题，`book.typography: bold / light` 管共享字重阶梯，`book.fonts` 管字体角色，`book.brand` 管身份要求。两套排印与五种主题可组合，基础字体统一为思源黑体/宋体。正文留在 HTML，SVG 可作为语义图解嵌入；不把整页文字画进 SVG。

## 六栏是一组对齐轴

稳定的是版心边缘、栏间与文字层级；可变的是跨几栏、从哪里开始、何时停顿。

- **4＋2**：主文与旁注；每条注释和对应段落在同一个 Grid 行组，下一组由两侧较高者决定起点。
- **2＋4**：短导语先出现，主文稍后进入；窄栏只放短导语和标签，不承载长文章。
- **跨栏停顿**：摘句从正文抽出，给第二种阅读速度；引用保留原话，禁止为装饰而编造金句。
- **3＋3 续读**：完整段落在两栏中错开起点；可以增加行组，放不下时拆页，不截断、不缩小正文。
- **主图＋伴随图**：大小与先后表达场景、细节或不同视角；每张图有自己的图注。源图没有真实联系时，不把拼图说成同一事件记录。
- **图版＋解读**：一张主体完整的图，与邻近解释建立对应。示意图、地图、统计图各有自己的事实要求。

当前 `RHYTHM / MARGINALIA / PLATE / SEQUENCE / PHOTO_OPEN / READING / MASONRY / CONTACT` 共用 `canon.editorial_grid()`，采用六轨 CSS Grid；文字按内容自然流动，摄影图位按构图分配基线行数。外层沿用文字栈、网格测量、原文核对和 PDF 门禁。它们是可复用组合，旧版式继续可用。更多层叠、多图比例与跨页变奏在取得实际样张证据后加入，不通过任意 HTML 块绕过引擎。

## 三个尺度安排节奏

**整册**：在缩略图上比较相邻页的图片面积、文字密度、标题位置和留白。阅读、观看、查阅、操作的任务变化，应在翻页时看得见。查阅区可以连续使用相同版式；不为了“每页不同”打断时间轴和目录。

**单页**：在 `page-plan.md` 写清“第一眼入口 → 主要阅读区 → 停顿点 → 继续方向”。入口可以是照片、主张、问题或有上下文的数字。吸引读者停下来的理由必须来自本页内容。

选择入口时，场景先于解释可用 `PHOTO_OPEN`，已有阅读动机的长文用 `READING`，需要建立主题再解释时用标题开场。连续阅读可保持两页同一结构，以栏目、篇名和续读标签连接；在文章边界安排图版或摄影停顿。相邻页不同，并不是比内容连贯更高的目标。

**组件**：栏目字、旁注、图注、细线、编号保持固定含义。短线负责分组，编号负责定位，摘句负责强调；不用同等醒目的卡片包住所有信息。

明暗交替只是一种节奏手段。黑白缩略图仍能分清主次，才说明结构在工作。正文密集页与安静页都可以吸睛，不把每一页做成海报。

## 跨主题共享的摄影偏好

本 skill 的摄影默认偏好是：照片以 cover 铺满图位，主摄影区优先延伸到裁切边；不因为选了 Swiss、Editorial、风格派或孟菲斯，就给每张照片套统一的白框、小卡片或圆角。书卷感由文字、栏目、比例与节奏建立，摄影出血也可以克制。留白用于阅读和分组，不机械地包围每一张照片。页边几何与结构装饰也应避开照片，不能把出血摄影重新盖成带边框的图；共用引擎在最终位置上保护摄影区。

“铺满图位”与“整页照片”分别判断：前者避免图位内部空边，后者由页面任务决定。摄影区可在上、下、侧边或连续跨页；短简报仍可用中小幅照片。依据实际主体选择比例和 focus，不拉伸人物或风景。图解、标本、地图、标识和二维码按完整可读的内容资产处理，用 PLATE / contain，不为铺满裁掉信息。

| 摄影结构 | 当前实现 | 选择与检查 |
|---|---|---|
| 顶部整幅、图下阅读 | PHOTO_OPEN（默认顶部及左右到裁切边）、T | 图注随图，主体完整，正文不压入图像；明确需要内收时 PHOTO_OPEN 写 bleed: inset |
| 上部阅读、底部宽景 | B | 照片到左、右、底边；按内容选 photo_rows，图上小字核真实对比 |
| 全高侧图 | SL / SR / MIX side | 内沿对齐网格，外沿到裁切边；文字栏宽维持阅读尺度 |
| 同一张照片的连续跨页 | SPREAD_H / SPREAD_P | 偶数左页与下一奇数右页共用一次裁切；合页核中缝，单页核阅读 |
| 有边界的瀑布流六图 | MASONRY | 六轨按2＋2＋2合并为三条独立图流；默认从页顶出血，接缝错开、底边收齐，标题及编号图注在图流之后；外侧照片到页边 |
| 主图与接触印样 | CONTACT | 一幅宽景统领两行六图，大小建立主次；真实图像关系由内容决定 |
| 主图＋两个补充视角 | SEQUENCE / MIX | 照片提供不同信息，说明与对应图像相邻 |

MASONRY 借鉴 a4-editorial 的六图摄影页：图片先形成约三分之二页高的连续观看区，三列内部接缝各自发生，形成瀑布流；横竖图缝统一为四分之一基线行距（A4为7px），照片向栏间延展，缝的中轴仍与六轨栏间中轴对齐。标题不占据图流上方，逐图说明按列先上后下集中置后并关联到对应图片；照片上不贴白底编号或文字标签。六轨是版心对齐轴，外侧照片向裁切边延展后，视觉宽度可以大于中列。它适用于固定页的有边界编排，当前不提供任意数量图片的网页自动排布。CONTACT 中的六张图应各有信息价值，不能为数量重复填图。素材不够时选更少图的结构。字号、单一强调色和功能资产规则继续生效；结构选择不覆盖品牌要求。

这里的出血指视觉延伸至成品裁切边；额外印刷出血、裁切标记和 PDF 页面框按实际输出要求处理。真实照片样例由项目提供，结构样例见 templates/book.photography.yaml，控制预览为 `dev/gallery/photography_shared.jpg` 和 `dev/previews/book.photography.preview.jpg`。

## 插图进入内容

先写一句“读者通过这张图会看懂什么”，再选择照片、SVG 图解或绘制插画：

| 任务 | 图的组织 | 验收 |
|---|---|---|
| 观察对象 | 完整主体＋编号局部＋邻近说明 | 标注确实指向对应部位，主体不裁掉 |
| 理解过程 | 阶段、连接、条件与结果 | 箭头有语义，先后与原稿一致 |
| 比较证据 | 同尺度的并列图或图表 | 单位、范围、来源可追溯 |
| 进入场景 | 环境、动作、细节的摄影组合 | 每张图片提供不同信息，图注不串图 |

`art.py` 的种子背景是气氛素材，不能替代上述插图；无图页完全可以靠文字构图成立。`PLATE / SEQUENCE / PHOTO_OPEN / MASONRY / CONTACT` 要求实际素材，缺图时明确报错。图版的 `caption / annotations` 是内容，参与原文核对；不可用装饰标记隐藏信息缺漏。

## 样张与验收

首轮样张覆盖正文页、图版或多图页、密集查阅页；同一内容至少比较一次结构变化。需要验证主题可复用性时，保持 layout 与内容不变，只换 style/colors/fonts，查看自然换行和实际 PDF。主题允许改变文字度量，但不另写一套位置补丁。

样例：`templates/book.editorial.zh.yaml`；叶片示意源图在开发资源 `dev/sample_photos/leaf-study.svg`。照片由项目提供，开发自测用合成图，仅验证构建与布局。视觉评估需另用真实照片。

连续阅读样例：`templates/book.reading.yaml`，两篇原创观察文章、中文与英文各 8 页。它验证段落顺序、正文尺寸、共用篇名和明确的续页分配；不代表任意长文已具备自动分页能力。系列写法由 layouts.md §8 统一说明。

开发预览：`dev/gallery/editorial_same_copy.jpg` 比较同一文案的旧布局与新布局；`dev/gallery/editorial_grid.jpg` 展示四种页面处理；`dev/gallery/styles_overview.jpg` 展示当前保留的五种主题，`dev/gallery/typography_profiles.jpg` 比较同主题的两套共享排印。合成图构建预览为 `dev/previews/book.editorial.zh.preview.jpg`。

第二轮预览：`dev/gallery/editorial_reading.jpg` 展示实际 PDF 中的双语首页与续页，`dev/gallery/editorial_opening.jpg` 用合成素材展示图片开场结构，`dev/previews/book.reading.preview.jpg` 展示整册。

技术门禁之后，按 review.md 检查读者能否快速识别主题、读下去、找到下一处入口。整册拼图、单页、成品尺寸及导出 PDF 都要看；CSS 类名存在或截图无溢出不代表设计成立。
