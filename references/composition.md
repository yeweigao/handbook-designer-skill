# 构图与整册节奏

从材料、阅读任务与视觉主张推导页面。Folio 的 [瑞士主义底座](swiss.md) 统一网格、左齐右松、比例、留白与图文秩序；HTML/CSS/SVG 表达具体构图，没有整页布局注册表。

## 三个尺度

- **整册**：开场让人理解主题与读法；正文展开证据；查阅区稳定；末尾给实际行动。章节转换和呼吸页要有内容依据，不按固定间隔插大图或换底色。
- **页面/跨页**：先定读者第一眼看什么、下一步读哪里。照片、摘句、数据或正文都能当主角。短稿允许留白，密集页依靠层级和分组；不为平均空白率塞装饰。
- **信息组**：标签和值、数字和单位、任务和产出、图和图注保持关系。普通长文可续排，日期/联系人等查阅信息用完整组，不能只因累计字数多就分栏。

## CSS 的责任

`folio.css`（旧项目可能叫 `design.css`）固定字阶、字重、颜色、节奏、网格和组件，页面通过 HTML 组合它们；`book.css` 只补确有缺口的局部关系，语言覆盖遵守同一边界。六栏 / 十二栏细分、6mm 栏距与 28px 基线是共同起点，实际行高、尺寸和对齐决定页面秩序。扩展条件见 [style](style.md)，不能把构图自主权解释成另写一套主题。

完整页面作为可读示例保存，不进入家族模板菜单。可以延续同系列结构，也可以为新内容调整；不强制每页都不同，不以类名或相邻页相似度评优秀。

## 照片与跨页

真实主图先看主体、方向、背景安静区及裁切余量，再决定字落纸面还是图上。要贴边时明确定义出血，不把正文行长也铺满。图解、地图、logo 等保留完整信息，不为了铺满裁掉。

摄影页与文字页沿用同样的对齐线、字阶、图注和编号规则。满版适合交代场所或情绪，网格内单图适合观察主体，主图配细节适合过程与证据，序列适合时间或比较；选择由材料决定，不强制所有照片铺满。大面积色面、巨字与图文叠放同样先服务阅读任务。

跨页是两张物理页的联合构图：同一 `data-spread`、正确左右位置、图像坐标连续、关键主体和文字避中缝。封面是独立右页时，第一组面对页通常为 2–3。加删页必须重查跨页、页码、目录与装订，不能并排两张独立页就称为联合跨页。

## 行程、图表与分析

时间轴首先区分日期顺序、持续时间和阶段。只有按真实时间比例排布的轴才能暗示时长；等距节点表达顺序时明确日期，行程还要保留移动、等待、集合与休息。密集行程优先用共用时间列和稳定分组，不把每站拆成重复底色卡片。

企业图表围绕一个可证明的结论组织。比较看条形，时间变化看折线，构成看堆积，增减归因看瀑布；保留单位、期间、分母、基线与来源。图表标题、直接标注和脚注仍使用 Folio 的字阶与网格；图例、线型和颜色含义全册一致。定量绘图及示例见 [图表说明](charts.md)。

五力、定位矩阵、价值链等框架表达定性判断时，用名称、关系、依据和限定条件组织；没有评分方法就不随意画百分比、打分雷达或把面积当实力。采用咨询报告的清晰信息层级，不用机构风格名替代数据严谨性。

正文、密集页、无图页和最弱页同样要完成设计。最终判断见 [review](review.md)，作者标记及物理约束见 [contract](contract.md)。
