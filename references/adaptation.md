# 文案与版面适配

先理解语义角色，再决定构图。原稿、提取稿、采用稿、作者源和 PDF 应可追溯；不能改核对基线只为消除漏文告警。

## 授权与内容模式

`project.json.content_mode` 按用户要求选择，写 brief。事实、数字、限定词、名称、时间地点与承诺不能因排版改变。原文件保留 `sources/original/`，稳定段记录在 `segments.json`；在项目采用记录中列“原句→采用句、原因、内容 ID/页、事实核对”。

| 模式 | 自动覆盖解释 | 仍须人工判断 |
|---|---|---|
| carry | MISSING/EXTRA 硬项，ORDER 提示 | 调序是否改变意义、真实非原文元素是否获授权 |
| translate | 默认语言按 carry；译文可见并进入该语言 PDF | 译义、数字/条件对应、各语言分页指代 |
| polish | MISSING/EXTRA/ORDER 提示 | 按授权逐段核所有独立信息及限定条件 |
| frozen | MISSING/ORDER/EXTRA 全为硬项；不接受 adapt.json | 原稿页对应（若约定）、图文归属及文字原样 |

覆盖不是严格原文段 ID 与 HTML ID 一一对应：作者可拆/合段，HTML 的稳定内容 ID 服务多语言和编辑；原稿段 ID 服务原始定位。覆盖结合句子、DOM 可见性及 PDF 文字。隐藏、透明、页外及裁掉的文字不能算交付；装饰标记不能豁免正文。

## 原稿格式与采用声明

序号可能是任务顺序，斜杠可能代替列也可能是真标点；先判断再重组。“栏目字/03/活动名/日期地点”各有角色，不能把原稿上的大字都当主标题。读者依赖的步骤、标签和值、限定条件要保持。

确认为非读者内容的备注、版本记录，或无语义的前缀，可逐项在 `sources/adapt.json` 声明并写理由：

```json
{
  "omit": [{"segment":"s0003","reason":"原稿内部备注，不印"}],
  "strip": [{"segment":"s0010","text":"亮点一：","reason":"栏目标签另行组织"}],
  "extra": [{"content":"cover-eyebrow","reason":"已授权添加的栏目导航"}]
}
```

声明是可审阅的取舍，不是删正文许可。用户的改写授权仍须明确；冻结模式不能用此文件。页码/页眉等结构性 aux 可被自动覆盖豁免，仍要人工核对，不能把事实内容标 aux 来放行自创文字。`sources/user-edits.json` 仅由 Folio 用户本人编辑产生，agent 不可借此放行自己的改写。

## 分组、阅读与页序

叙述适合连续正文，时间/地点/费用适合成组查阅，统计保留数字/单位/口径，任务保留指令/行动/产出及书写空间。短导语不机械分栏，不能让标签和值分居两页。长正文可用 [续排](blocks.md)，图注和图、标题和下文保持关系。

在 [page-plan](../templates/page-plan.md) 用一张简表写任务、原稿定位/采用 ID、主角、阅读顺序与系列/跨页关系。概览回答有哪些/去哪里，章扉说明为何进入这一章，详情展开证据；没有新增阅读价值的重复页应调整内容去向，不为页数补空洞文字。

合/拆/调序后复查章节识别、目录、页码/书签、跨页单双页、封面封底与装订。修改反馈按共用规则查完整系列及续页；无关已认可页保持。照片主体、“见右图”、翻译语义与任务是否可执行属于实际 PDF 审稿，不能由字符串检查替代。
