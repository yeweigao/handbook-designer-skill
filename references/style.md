# CSS 基因、字体与品牌

家族给作品共同语言，作者决定页面构图。当前推荐为 [Folio CSS](../families/folio/README.md)，与 Folio 编辑器共用品牌。以 [瑞士主义](swiss.md) 的网格、层级、比例与留白为共同底座；文字、摄影、行程与图表共享原子和布局。Campus v1.1 保留作历史方案；家族清单以 `python3 hb/core/family.py list` 为准。历史画廊的主题名称不表示当前存在同名可用家族。

## 主题与局部补丁

正式分发为 `families/folio/folio.css`，由同一组源模块生成；项目初始化原样复制，`project.json.styles` 按 `folio.css`、`book.css` 顺序加载。旧项目的 `design.css` 继续作为自己的冻结主题，不重命名、不静默升级。家族元数据中的 `css` 指定来源文件，缺省为历史名称 `design.css`。

主题不是可随手参考的调色板：文字角色、字号字重、节奏、网格、颜色、图像和功能组件都从它继承。先组合原子，再选可拆的布局/组件；完整页面的差异主要来自内容、比例和组合。

`book.css` 默认留空。满足以下条件才新增一项补丁：

- 现有 API 无法表达一个具体阅读任务，而不是“想更高级”；先指出尝试过的组合和缺口。
- 补丁只解决局部几何、取景或已授权品牌适配，用现有 token，作用域限于该页/组件。颜色仍使用语义角色并实测对比度。
- 在 `style-lock.md` 合并记下任务、缺口、范围与实际验证；不逐条抄 CSS。撤掉补丁时，作品仍应保留 Folio 的排印与秩序。

不得把字号、字重、间距、行距、字体与全局组件皮肤重新定义为另一套系统；内联、`lang/*.css`、`edits.css` 与 `!important` 不是绕行出口。用户明确要求另一套主题时，作为主题派生/升级任务说明影响并重新审稿，不把它伪装成局部补丁。单册补丁无需修改 Skill 的共享源模块，也不自动晋升为公共组件。

`styles[0]` 的原始字节须与 `family.sha256` 一致。哈希校验发现的是冻结副本被修改；静态样式检查只覆盖部分漂移模式，不能证明所有 CSS 都合规，更不能判定审美。已授权升级应保存基线、记录来源差异与新哈希、重新验收；不能改哈希或加 waiver 消掉意外修改。

## 字体资源

字体角色用实际本地静态文件。每个需要的字重/斜体在 project.json.fonts 声明；可变字体先用 `font_static.py` 或 `family.py fonts` 实例化。字体准备与正式 render 分开，不后台下载、不先用系统字后下轮换样。补新文字后查字形与实际使用字体，必要时显式重建项目字体。

Folio 使用 Noto Serif SC / Noto Sans SC / Inter，数字与正文同族。源码字体按 family.json.source 的文件名放到 `HB_FONT_DIR` 或用户缓存（`python3 hb/core/fonts.py install` 准备；加 `--system` 可同时复制给其他应用）；三者都是 OFL，可随项目交付。项目源包保留实际静态文件与授权文本，不依赖交付对象机器上的系统字体。准备细节见 [delivery](delivery.md)。

## 排印双结构

默认 `fl-type-bold`：标题为 Noto Serif SC；`fl-type-light`：标题为 Noto Sans SC。模式可放在整页或独立区域，布局和摄影能力相同。正文用 Noto Sans SC，阅读衬线角色用 Noto Serif SC，功能标签与数字用 Inter / Noto Sans SC；`fl-number` 只决定字体角色与等宽数字，不改变字重。

| CSS 字号 | bold 字重 | light 字重 |
|---|---:|---:|
| ≥ 64 px | 900 | 200 |
| 44–63 px | 700 | 250 |
| 32–43 px | 700 | 300 |
| 20–31 px | 600 | 400 |
| 16–19 px | 400 | 400 |
| 14–15 px | 500 | 500 |
| < 14 px | 600 | 600 |

常用字阶为 11 / 13 / 14 / 16 / 20 / 24 / 32 / 46 / 64 / 112 px；巨字扩展提供 196 px（giant）与 280 px（colossal），仍沿用 ≥64 px 的字重。CSS px 按物理印刷尺寸解释，不随纸张缩放。light 的大字更轻，小字增加墨色；bold 使用衬线与较重标题形成另一种层级。选少量适合内容的层级即可，不要求每页展示完整阶梯。

字号原子同时选择相应字重；从已定义档位中选择，不在补丁里另造字号。bold 中字号层级的强调比基础字重增加 200、最高 900；light 保持同级字重。数字与其他文字共用同一张字重表：bold 取该档加厚值、light 取该档轻值，不另设数字专用字重。表格数值和单位保持成组；数字不因承担装饰作用而删掉来源或语义。

连续阅读默认左齐右松。数字列可右对齐，小型对照标签和短标识可按构图调整；不要把中文正文拉成机械等宽行。标题断行按词义与视觉长度决定，字号越大越要检查标点、孤字及实际字形。

## 用色与图形

按纸面、正文、标题、强调、辅助与反白角色选组合，不用品牌色绕过对比度。默认一种强调色，用在焦点、当前项、重要路径或图表主序列；品牌可以替换它，照片可以保留自然颜色，多序列图表可按语义增加辅助色及线型。强调色使用多少由信息决定，不以红黑白外观替代结构。照片处理、字重和行长根据读者任务决定；栏目、序号、主标题不因原稿字号大就混成同一层。

品牌标志完整、正确用色且有权使用。需要延展时，用独立 SVG/CSS 从源形提炼章节锚点或背景，记录与内容的关系；不替代正式 logo，不要求每页都有。示例 [Acme](../brands/acme/README.md) 仅用于展示资源组织。

可读性硬下限只有 [contract](contract.md) 定义；家族可以提高，不能降低。最终逐页判断见 [review](review.md)。

## 原子、布局与组件

Folio CSS 提供 token、基础规则、可选布局、组件与表现手法，原子负责可组合的局部控制；使用时只复制生成好的 `folio.css`，不需要 CSS 构建依赖。`.fl-area` 负责纸张安全版心，`.fl-grid` 与 `.fl-l-*` 负责内部关系，两者可以独立组合。具体类名、层叠次序和可覆盖项以 [家族文档](../families/folio/README.md) 为准。

[正式配方索引](../families/folio/recipe-index.md) 按原子、布局、组件和变奏定位 HTML 配方。照片路径是需要替换的本项目素材示例，成品仍需补内容 ID、来源、角色与必要的叠放/出血声明。共用组件提供索引、图注、数字、时间轴等功能结构，选择器保持低优先级，允许原子覆写；普通 HTML 配方也可自行拆解。引用与段落不自动附加侧边线或底色。照片的组图、出血和跨页也使用同一组颜色、字体与间距。

可选布局允许拆解重组；它们不成为运行时注册菜单。封面与页面节奏优先由现有类的组合实现；必要 CSS 沿用本页的补丁契约。不能把配方的示例文字、坐标与装饰原样套到新材料上。
