# 视觉风格、字体与配色

## 1. 四种风格

当前 `book.style` 只维护下列四种。风格只管字体、色彩、线条、图像处理和图形语言；布局仍共用六栏网格，见 composition.md。

| style | 视觉方向 | 适用内容 |
|---|---|---|
| `photo` | Photo · 纪实摄影杂志。真实摄影、衬线标题、无衬线正文、黑体功能信息，少量暖金点缀 | 研学、旅行、现场叙事、自然观察 |
| `swiss` | Swiss Minimal · 瑞士极简。中性纸面、一个强调色，思源黑体；默认轻盈排印，也可选厚重排印 | 指南、机构手册、理性叙述、信息整理 |
| `editorial` | Editorial · 编辑杂志。宋体标题与正文、暖纸、黑体功能信息、细线与中小图片 | 家长手册、阅读手册、回顾与报告 |
| `stijl` | 风格派。三原色分区、结构线、网格构成；保留 classic / tone / beat | 展览、设计、机构介绍、构成感画册 |

geo / notebook / inkwash / papercut / riso / aurora / nebula 已退出当前选择，构建时明确报错；旧项目需选择上述四种之一重新试排。历史样张留在开发归档，不作为当前方向选项。

Swiss Minimal 不再提供撞色变体或无内容意义的大圆装饰。风格派保留自己的图形语言，同样可选择共享的厚重或轻盈排印。`stijl` 可写 `book.look: classic / tone / beat`；其他风格不写 look。

## 2. 字体与共享排印

主题、排印、字体分开：`book.style` 决定视觉语言，`book.typography` 决定字重与字号的关系，`book.fonts` 决定实际字体家族。四种主题都支持两套排印，不为每种组合另造皮肤。

### 2.1 两款基础字体

默认全部使用 **思源黑体 Noto Sans SC / 思源宋体 Noto Serif SC**，中英文同源，不自动插入 Inter。字体以真实子集嵌入 HTML / PDF，许可随字体目录保存。

| 主题 | 标题 | 正文 | 栏目、页码、图表标签 |
|---|---|---|---|
| Photo | 思源宋体 | 思源黑体 | 思源黑体 |
| Swiss Minimal | 思源黑体 | 思源黑体 | 思源黑体 |
| Editorial | 思源宋体 | 思源宋体 | 思源黑体 |
| 风格派 | 思源宋体 | 思源黑体 | 思源黑体 |

### 2.2 两套共享字重阶梯

`book.typography: bold / light` 独立于主题。默认 Swiss 为 light，其余为 bold；任一主题均可切换。A4 默认正文 16px 时：

| 实际字号 | bold 厚重型 | light 轻盈型 |
|---|---|---|
| ≥64px | 900 超粗 | 200 ExtraLight |
| 44–63px | 700 | 250 |
| 32–43px | 700 | 300 Light |
| 20–31px | 600 | 400 Regular |
| 16–19px | 400 Regular | 400 Regular |
| 14–15px | 500 Medium | 500 Medium |
| <14px | 600 SemiBold | 600 SemiBold |

14px 正文与小画布按相对于正文字号的比例缩放。字重加粗不能代替足够字号。标题自动缩小时重算字重，在线编辑和 PDF 使用相同策略。

light 遵循同页字号越小字重越稳，正文和小字至少400；内联强调保留语义和强调色，不任意跳到700/900。bold 允许正文内联强调增强字重。规则进入共用排版和 `cn-weight` 检查；图片与外部 SVG 内部的文字由素材自身负责，不被重绘。

引擎导出真实200/250/300静态字形，不能仅在CSS写200而让浏览器用Regular代替。两款思源字体均有实际所需字重，PDF仍使用TrueType静态子集。

```yaml
book:
  style: editorial
  typography: light     # 同一个 Editorial，也可选 bold
```

**可选100 Thin。** 当前内嵌的思源黑体 Noto Sans SC 的 wght 轴为100–900；思源宋体 Noto Serif SC为200–900。`typography: light` 保持默认大字200，需要更轻的大标题时可加 `book.display_weight: 100`；只影响至少四倍正文字号的大字，正文与小字下限不变。它是共享排印选项，不属于某个主题。实际PDF字面比较见 `dev/gallery/type_100.jpg`。所选标题字体必须提供真实100字重，不支持时明确报错，不伪造宋体100或擅自换字族。

```yaml
book:
  style: swiss
  typography: light
  display_weight: 100
  # Editorial等主题要使用100时，可明确 fonts: sans 采用思源黑体标题。
```

### 2.3 按需扩展字体

基础成品无需扩展字体。可选 Inter（无衬线）、Playfair Display（展示衬线）、Source Serif 4（阅读衬线）、JetBrains Mono（功能性等宽），只有明确写入角色才加载。light 的标题字体须支持真实200字重；Playfair从400起，应在bold中使用，或改用Source Serif 4。

```yaml
book:
  style: editorial
  typography: light
  fonts:
    preset: serif
    title: [source-serif-4, noto-serif-sc]
    body: [source-serif-4, noto-serif-sc]
    label: [inter, noto-sans-sc]
```

`python3 hb/fonts.py fetch noto-sans-sc noto-serif-sc` 准备基础字体；扩展使用注册ID按需fetch。缺字体的系统回退可用于预览，正式验收应确认实际字体与字重已加载。

### 2.4 Editorial 的克制编排

参考用户指定的 Monocle 式书卷感：暖米白纸面（默认 `#FDFCF3`）、宋体承担主要阅读、黑体仅承担功能信息、发丝分隔线、中小幅矩形图片与整齐白边。不自动生成装饰性圆环或气氛插画，不强制戏剧化大图开篇。

三栏用于短简报、并列条目及有独立标题的短文，可用既有 `PAPER + cols`；连续长文用稳定行长的 `READING / MARGINALIA`。三栏是可选布局组合，不是强制把每页长文挤进窄栏。样例 `templates/book.editorial.zh.yaml`。

标题克制还需要选择合适的字级和版式，bold 方案不要求每页都出现巨大标题；light 也不意味着正文变细。屏幕暖纸色表达视觉气质，实际纸张、吸墨与印刷效果需成品打样。

成品同时看字面、字级、字重、行距、行长和段间距。代表页在成品尺寸及实际 PDF 查看，包含长文、密集资料页、图注和联系方式，不以字体文件存在代替视觉验收。

## 3. 克制配色

默认沿用风格自身配色，不按色差自动切换撞色。当前预设仅保留：

| colors | 用途 |
|---|---|
| `nature` | Photo：森林绿、暖纸、少量金色 |
| `campus` | Photo / Editorial：墨蓝、暖纸、少量赭金 |
| `ink` | Editorial：纸与墨、中性灰 |
| `swiss` | Swiss：中性纸面、墨字、一个砖红强调色 |

风格派默认沿用自身三原色/几何配色，不用上述预设覆盖其识别。已有品牌色仍可用角色字典明确指定。

## 4. 渐变与图像

当前不提供预设渐变标题；Swiss 拒绝 gradient。跨主题的铺满、出血和组图偏好见 composition.md。摄影优先保留真实画面和可解释的裁切，是否黑白在项目里决定；`book.duotone: off` 保留原色，单图可显式设 duo。

没有照片时选择清楚的文字构图或准备内容相关的插图。Photo 的占位不是正式摄影；Swiss 的空图位不生成随机插画。`PLATE / SEQUENCE / PHOTO_OPEN` 必须有实际素材。素材与图文关系见 images.md。

## 5. 图形语言

所有图片位遵守共用网格，不随机改变裁切形状。Photo 依靠摄影叙事，Editorial 依靠排印、栏目与细线，Swiss 依靠对齐、比例、字重和留白；风格派使用自身结构性图形。项目需要品牌图形时见 §7.1，不为填空而增加装饰。

## 6. 字号与画布

网格、字号档、行宽和让位顺序由 layouts.md §0 统一说明。A4 默认正文 16px / 行距 28；`book.body:14` 与小画布使用紧凑网格。文字超量应重排或按完整段落续页，不能靠细字或缩正文换容量。

西文可用 `book.typesetting: editorial`：正文行距为字号的 1.5 倍，导语为正文 1.25 倍；结构仍吸共用网格。默认 grid 排印与此选项均需看实际 PDF。

## 7. 品牌包

`book.brand` 读取 `brands/<名字>/brand.yaml`，项目明确设置优先于品牌默认。包内可保存颜色角色、字体角色、logo、联系信息和口吻。虚构样例 acme 使用克制墨蓝和 magazine 字体；新建见 workflows/brand.md。

正式 logo 保留完整原件，单色版本按纸面选择深/浅色；`logo: true / false` 控制页面应用，末页 `contact: false` 可关闭品牌联系信息。身份要求不由风格皮肤替代。

### 7.1 可选扩展：品牌图形延展（暗纹与超级图形）

这是现有视觉风格之上的可选品牌语言，适用于需要强化识别的品牌画册、项目手册和系列出版物。用户要求时启用；规划品牌方向时也可将它作为可选方案，依据brief及既有授权取舍。有合适的图形结构才采用，不要求每本册子或每页都有暗纹。正式logo承担识别，衍生图形承担构图、节奏与内容联系。

**先读懂源形（仅限用户自有或已获授权的品牌标志）。** 查看实际标志，分清用户指定的图形符号、字标和组合标；已有明确指定时直接沿用。保留正式logo原件及品牌规范。优先使用原始矢量；用户自有品牌的清晰几何符号可依源图矢量重绘，但须对照比例、轴线、开口、线宽与交织连接，不把近似通用几何当成原标志，也不得擅自重绘无授权的第三方商标。重绘资产作为项目衍生图形记录，不冒称官方文件。

**让结构服务内容。** 从源符号的交汇、围合、平行、开口和方向等特征寻找本页构图关系。例如协作内容可呼应交汇，安全/支持可呼应围合，连续进程可呼应同向延伸；这些只是设计者针对本册的解释，不能声称是官方品牌寓意。先在page-plan写“内容任务→源形特征→构图→隐喻”，再决定角度与尺度。

| 应用方式 | 构图方法与作用 |
|---|---|
| 低对比暗纹 | 在阅读纸面上轻显品牌结构，顺应信息布局，保持文字与功能图清楚 |
| 页边一角 | 完整母形等比放大、旋转和移动，借纸边只露转角或交汇处，形态与留白共同构图 |
| 章节锚点 | 放大母形支撑章节转换，与章号、主标题建立主次；阅读页可减弱或留净纸，形成节奏 |
| 跨页超级图形 | 两张真实面对页共用一枚超大完整母形，连接关联内容；先设计合页，再拆为偶数左页与下一奇数右页 |

**保持母形与整册秩序。** 使用完整源路径作等比变换，局部由纸边或前景自然显现；避免页内矩形切口造成标志断裂。相邻/同系列联合考虑，各页取景服务其内容；同册变化应保持同源识别，不靠随机旋转制造差异。允许不使用图形的净页，避免每页同一大小、同一位置反复盖章。

**浓度与保护。** 按纸面、文字密度和实际输出判断暗纹强弱，约5%组透明度可作试排起点，具体数值属于项目决定。浅纸可取品牌色，主题色纸面可取合适的浅/深色；正式logo仍按品牌包规则使用。默认保护原照片、QR/logo与文字，图上应用需有明确构图依据。实际PDF检查主体、可读性和中缝，印刷呈色以打样为准。

**方案与落版交接。** brief记是否启用、指定源形与应用范围；page-plan记录使用页/面对页、源形特征、尺度/角度、内容联系及保护区域，不使用的页无需硬配寓意。源SVG放在本项目photos/_assets/并记录出处，正式logo另保留。共用可选矢量层及参数见blocks.md的brand_graphic；引擎执行已有的变换与保护，源形选择和逐页设计由执行者完成，不自动解读logo。仅写book.brand并不会自动完成本项目的品牌图形方案。后置视觉总监按review.md的H17复核；关闭延展层后原版式应不变。

## 8. 颜色角色与用色

| 角色 | YAML | 用途 |
|---|---|---|
| 背景 | background | 纸色 |
| 次级背景 | secondary_bg | 资料分区、浅底 |
| 主色 | primary | 主题识别、少量重点 |
| 强调色 | accent | 少量数字、标记、深底点缀 |
| 次强调色 | secondary_accent | 局部提示 |
| 正文 | body_text | 正文、表格 |

旧颜色键 A / B / G / GOLD / INK / PAPER 继续识别。`color_mode: accent` 使用克制点缀；`mono` 使用单色策略。`auto` 沿用风格默认。`clash` 已退出当前模式，不能继续推荐经典撞色方案。

Swiss 固定 mono，只取 primary 为一个强调色；次级背景归入中性纸面，其他配色角色不制造第二种彩色。风格派的多色来自明确图形角色，不能推导为 Swiss 也应大面积撞色。

`surface: paper / A / B / dark` 分别表示纸色、主色纸面、浅底与深墨纸面。显式纸面按任务使用，非默认每页换色；文字按真实对比度取白或墨。`colorqa.py` 提示连续重色页，`qa.py` 核小字对比，图像与 logo 另看成品。控制预览见 `dev/gallery/swiss_surfaces.jpg`。
