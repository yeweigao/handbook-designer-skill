# CSS 基因、字体与品牌

家族给作品共同语言，作者决定页面构图。当前推荐为 [Folio CSS](../families/folio/README.md)，与 Folio 编辑器共用品牌。以 [瑞士主义](swiss.md) 的网格、层级、比例与留白为共同底座；文字、摄影、行程与图表共享原子和布局。Campus v1.1 保留作历史方案；家族清单以 `python3 hb/core/family.py list` 为准。历史画廊的主题名称不表示当前存在同名可用家族。

## 冻结与分工

- `families/<家族>/design.css` 是创建项目的来源，family.json 提供版本、画布与字体角色。
- 项目 `design.css` 是本项目的权威基因：颜色角色、字体角色、字号/行距阶梯、线条/间距与低层原语。创建时复制并在 project.json 记录 name/version/sha256。
- `book.css` 是本书的整页构图；`lang/<lang>.css` 解决语言长度、断行及局部差异；Folio 规则暂存 edits.css，审阅后可并入本书 CSS。

家族更新不会静默改旧项目。项目改变基因时记原因与影响范围并审全册，主动更新来源记录。整页封面、双栏页或卡片页作为作品示例存在，不变成家族必选类。

## 字体资源

字体角色用实际本地静态文件。每个需要的字重/斜体在 project.json.fonts 声明；可变字体先用 `font_static.py` 或 `family.py fonts` 实例化。字体准备与正式 render 分开，不后台下载、不先用系统字后下轮换样。补新文字后查字形与实际使用字体，必要时显式重建项目字体。

Folio 使用 Noto Serif SC / Noto Sans SC / Inter，数字与正文同族。源码字体按 family.json.source 的文件名放到 `HB_FONT_DIR`、用户缓存或用户字体目录（`python3 hb/core/fonts.py install --system` 一次装好）；三者都是 OFL，可随项目交付。项目源包保留实际静态文件与授权文本，不依赖交付对象机器上的系统字体。准备细节见 [delivery](delivery.md)。

## 排印双结构

默认 `fl-type-bold`：标题为 Noto Serif SC；`fl-type-light`：标题为 Noto Sans SC。模式可放在整页或独立区域，布局和摄影能力相同。正文用 Noto Sans SC，阅读衬线角色用 Noto Serif SC，功能标签与数字用 Inter / Noto Sans SC；`fl-number` 只决定字体角色与等宽数字，不改变字重。

| CSS 字号 | bold 字重 | light 字重 |
|---|---:|---:|
| ≥ 64 px | 900 | 200 |
| 44–63 px | 700 | 250 |
| 32–43 px | 700 | 300 |
| 20–31 px | 600 | 400 |
| 16–19 px | 400 | 400 |
| 14–15 px | 500 | 500 |
| < 14 px | 600 | 600 |

常用字阶为 11 / 13 / 14 / 16 / 20 / 24 / 32 / 46 / 64 / 112 px；巨字扩展提供 196 px（giant）与 280 px（colossal），仍沿用 ≥64 px 的字重。CSS px 按物理印刷尺寸解释，不随纸张缩放。light 的大字更轻，小字增加墨色；bold 使用衬线与较重标题形成另一种层级。选少量适合内容的层级即可，不要求每页展示完整阶梯。

字号原子同时选择相应字重；手写其他字号时按上表显式配重。bold 中字号层级的强调比基础字重增加 200、最高 900；light 保持同级字重。数字与其他文字共用同一张字重表：bold 取该档加厚值、light 取该档轻值，不另设数字专用字重。表格数值和单位保持成组；数字不因承担装饰作用而删掉来源或语义。

连续阅读默认左齐右松。数字列可右对齐，小型对照标签和短标识可按构图调整；不要把中文正文拉成机械等宽行。标题断行按词义与视觉长度决定，字号越大越要检查标点、孤字及实际字形。

## 用色与图形

按纸面、正文、标题、强调、辅助与反白角色选组合，不用品牌色绕过对比度。默认一种强调色，用在焦点、当前项、重要路径或图表主序列；品牌可以替换它，照片可以保留自然颜色，多序列图表可按语义增加辅助色及线型。强调色使用多少由信息决定，不以红黑白外观替代结构。照片处理、字重和行长根据读者任务决定；栏目、序号、主标题不因原稿字号大就混成同一层。

品牌标志完整、正确用色且有权使用。需要延展时，用独立 SVG/CSS 从源形提炼章节锚点或背景，记录与内容的关系；不替代正式 logo，不要求每页都有。示例 [Acme](../brands/acme/README.md) 仅用于展示资源组织。

可读性硬下限只有 [contract](contract.md) 定义；家族可以提高，不能降低。最终逐页判断见 [review](review.md)。

## 原子、布局与组件

Folio CSS 提供 token、基础规则、可选布局、组件与表现手法，原子负责可组合的局部控制；使用时只复制生成好的 `design.css`，不需要 CSS 构建依赖。`.fl-area` 负责纸张安全版心，`.fl-grid` 与 `.fl-l-*` 负责内部关系，两者可以独立组合。具体类名、层叠次序和可覆盖项以 [家族文档](../families/folio/README.md) 为准。

[展示页](../dev/folio-css/index.html) 展示颜色角色、字阶字重、网格跨度、节奏、图片比例与焦点，再给出布局及可复制配方。共用组件提供索引、图注、数字、时间轴等功能结构，选择器保持低优先级，允许原子覆写；普通 HTML 配方也可自行拆解。引用与段落不自动附加侧边线或底色。照片的组图、出血和跨页也使用同一组颜色、字体与间距。

可选布局是作者工具，允许替换和拆解；它们不成为运行时注册菜单。专属封面、页面节奏仍由作者在 `book.css` 实现，不能把参考中的文字、位置与装饰原样套到新材料上。
