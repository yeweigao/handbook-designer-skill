# 视觉风格 · 字体 · 配色

外观由三个**互相独立**的旋钮决定（借鉴 ppt-master 的分层：风格只管“长什么样”，不写死颜色和字体）：

```yaml
book:
  style: photo        # 视觉风格：形状语言、装饰、留白、质感、照片/底图的处理
  fonts: magazine     # 字体方案：标题 / 正文 / 小标签 / 编号 四个角色各用什么字体
  colors: klein       # 配色：方案名，或 6 个颜色键
  gradient: spotlight # 可选：标题渐变（默认不开）
```
每种风格自带一套默认字体和配色，只写 `style` 就能得到完整的效果；`fonts`、`colors` 写了才覆盖。

效果图：`references/gallery/style_<风格>.jpg`（同一份 8 页内容排成 8 种无图风格）、`references/gallery/styles_overview.jpg`（11 种风格总览）、`references/gallery/palettes.jpg`（配色与渐变色卡）、`references/gallery/fonts.jpg`（字体样张）。

## 1. 视觉风格 book.style

效果图：`references/gallery/style_stijl.jpg`（经典）· `style_stijl_tone.jpg`（无线）· `style_stijl_beat.jpg`（节奏）· `style_geo.jpg`（孟菲斯）。
**风格派、孟菲斯、瑞士单色**不生成底图：图片位没照片时就是一块安静的色块，不写编号（这几种风格本来就用色块构图；风格派、瑞士单色的照片一律转黑白）。风格派的底层思想写在 `hb/stijl.py` 开头：线有层级（不是全画、也不是全不画），颜色是被线围出的格子、按内容角色给，阅读页内容为主——改它之前先读那段。

**无图模式**：除 `photo`、`stijl`、`geo` 外，没写 `image` 的页会按风格**自动生成底图**放在照片的位置（每页不同、全书统一，颜色跟着 `book.colors` 走）。版式、跨页、QA 全部照常（与纸面的交界见 §1.1）。某页拿到合适的照片就写上 `image: xxx.jpg`，照片和底图可以混用（照片页的图上文字用白字）。
**photo 风格没照片时**：写 `image: placeholder`——T/B、跨页是深色占位图，侧条、开窗是撞色色块 + 大号编号，封面类自动排成字体海报；照片到了再换。

怎么选：先看有没有好照片——有就 `photo`（照片想统一转黑白、版面要设计感时也可以用 `stijl`）；没有或照片不对题，按受众与气质选：正式/报告 → editorial；理性/机构 → swiss；展览/品牌画册/要设计感的机构介绍 → stijl（图多字多用 `look: beat`，要安静克制用 `look: tone`）；学生/动手 → notebook；传统文化 → inkwash；低龄 → papercut；低龄又要正文干净（装饰只在页边）→ geo；活动/文创 → riso；科技/年轻/当代 → aurora；AI/科技产品、发布会、投资人材料 → nebula。拿不准时排两种给用户看（只改一行 style，重跑即可）。

### photo 风格的视觉语法
照片是主角，这套语法让一本靠文字撑起来的册子像杂志而不是 Word 模板：
- 满版照片 + 图上白字，压暗由引擎按文字行带自动烘焙（整宽渐进，像 ND 渐变镜），不做逐段暗光晕——光晕会让页面显得脏。
- 内容页里照片不切硬边：照片在交界处（落在 28px 行线 / 栏间中线上）用约 1.5 行慢慢淡进半透明纸面（`book.paper`，默认 0.9，照片繁杂时调到 0.94），写字的纸面上照片淡淡透出来；过渡带里不放字。照片上只放标题、导语这类白字；纸面上的深色字由 QA 实测对比度，不够时自动在字下提亮一层纸。T / B / 跨页的照片往纸面里多铺约半页再淡成纯纸；侧条、开窗的照片往外多铺一圈。想要干净的不透明纸面和硬边：`book.edge: hard`。
- 金色：照片上的 Day 大字、关键数字、时段标签和 `color: gold` 用配色里的 GOLD（国家地理的黄）。
- 不用色块底、竖线装饰、图标、☐ 方框、▶ • ✓ 等符号；层级用字号、字重、间距、编号、小标签表达。
- 一个区域只用一种线（书写线或表格线）。图上一律白字；GOLD 只用于 ≥14px 的大字。

### 1.1 无图风格的设计语言
每种无图风格是一套完整的语言（底图在 `hb/art.py`，文字装饰在 `hb/styles.py`），不需要手工加装饰。共同规则：
- **取色像印刷**：只用 `book.colors` 的颜色，原色或向纸色调淡的固定档位；不做混浊的中间色，不加噪点。
- **边缘像矢量**：图形用距离场或超采样绘制，边缘干净，印刷放大也不发毛。
- **构图让位给文字**：文字左对齐，所以主体图形在可见区域的右半部、竖向中段。封面和封底这类整页高的画面，底部 26% 是文字区，图形在它上方收住。
- **字不压插画**：浅色插画（水墨、剪纸、手账、弥散……）上要写字时，插画停在文字上方一行，下面自动垫一块纸，字落在干净的纸上；深色插画（星云、编辑部）上写白字，照常压暗。
- **与纸面的交界**：除 photo 风格的照片（见上）外都是硬边，落在行线 / 栏间中线上；水墨的雾、弥散的光这些柔和感只在画面内部，不在交界处。平面风格不做“文字衬底”（纯色上的渐变衬底会显脏），文字压到图形上时 QA 会报，改构图或把文字挪到纸面上。

| 风格 | 形状词汇 | 线 | 颜色用法 | 构图 |
|---|---|---|---|---|
| editorial | 栏网格、基线、发丝大圆、一段金色弧线和一个金点 | 全部 0.5pt 发丝线 | 深色满版；强调色只出现一次 | 圆心落在栏线上，被基线平分 |
| swiss 单色 | 一个强调色圆点（封面、封底）、巨型强调色章节号 | 栏间 1px 竖线、1px 分隔线、页码上方细线 | 默认以白纸为主；可显式安排主题色/深墨整页纸面，见 §8；次级背景是中性浅灰 | 6 栏网格，左对齐；图片位没照片时是浅灰块 |
| swiss 撞色 | 圆、四分之一圆、方块、横杠 | 无线条 | 主色满版 70% / 墨色 20% / 纸色+强调 10%；纯平色 | 6 栏模块网格；三种构图（大圆出血、四分之一圆拼块、同心半圆）按页轮换 |
| notebook | 5mm 方格纸；便利贴 / 拍立得 / 索引卡+回形针（按页轮换）；和纸胶带、圆贴纸；四角星、波浪线、圆点 | 等宽单线 0.6pt、圆头 | 纸张 GOLD、胶带与照片 G、贴纸与点 OCH | 一件文具 + 一组涂鸦，统一投影（光从左上） |
| inkwash | 一轮日、四层远山、三只飞鸟、一方朱印 | 只有飞鸟是线 | 墨分五色：远山偏青、近山偏墨；朱红只给日与印 | 大面积留白；山脊清晰、向下化开成雾 |
| papercut | 双层纸太阳、纸云、五层波浪纸片 | 无描边 | 平涂纸色（原色与固定淡档） | 统一投影方向；最前一层就是纸面，波浪边过渡到正文 |
| riso | 半调网点太阳、拱门、细条纹、圆点 | 无描边 | 三色专色正片叠底，叠印处出现新颜色；每个色版一点套色偏移 | 海报式几何，集中在右侧 |
| aurora | 弥散光：上暖下冷 + 顶部光锥 | 卡片与胶囊的细白描边 | 由 G 推出亮蓝和天空蓝，GOLD 作暖光 | 柔和、无硬边 |
用户要的视觉语言完全不在这 9 种里（卡通插画、信息图、扁平图标风），说明本引擎擅长的是这几类，问清楚再决定是用 `{html}` 局部实现还是换做法。

## 2. 字体 book.fonts

全部开源、可免费商用、可嵌入 PDF。构建时只截取本书用到的字嵌进 HTML/PDF（换电脑字形不变），并在项目 `fonts/LICENSES.txt` 附上许可。
西文字体随 skill 附带；中文字体首次使用时自动下载（`python3 hb/fonts.py fetch` 可提前下载；`list` 查看状态）。下载不到时回退系统字体，构建不中断。

### 2.1 四套方案
| fonts | 标题（title） | 正文（body） | 气质 |
|---|---|---|---|
| `magazine`（photo/editorial 默认） | 思源宋体 Black + Playfair Display | **霞鹜新晰黑** | 杂志：粗宋标题压在照片上，正文有书卷味的黑体 |
| `serif` | **霞鹜新致宋** + Playfair Display | **霞鹜新致宋** + Source Serif 4 | 经典书籍：标题不加粗、雅致；适合长文、文化类 |
| `sans`（swiss/riso 默认） | 思源黑体 Black + Inter | **霞鹜新晰黑** + Inter | 现代理性：干净、强层级 |
| `hand`（notebook/papercut 默认） | **霞鹜文楷 GB** Medium + Caveat | **霞鹜文楷 GB** | 手写亲和：温暖，学生与亲子 |

小标签（label）与强调字（accent）随方案搭配（Oswald / Source Serif / Inter / Caveat）。这些是字体角色，不是文案角色：编号在不同组件里可能用title或accent，装饰字也没有独立的deco字体槽。须结合实际组件核对，不能认为写了accent就覆盖所有编号。

**英文项目要单独看西文组合。** 上表主要描述中文效果；纯西文项目的magazine正文实际默认Inter，sans也使用Inter。方案名叫magazine不代表英文正文已采用衬线，更不保证成品有杂志感。实际默认如下：

| 方案 | 西文标题 | 西文正文 | 西文标签 / 强调字 |
|---|---|---|---|
| magazine | Playfair Display | Inter | Oswald / Playfair Display Italic |
| serif | Playfair Display | Source Serif 4 | Source Serif 4 / 同族斜体 |
| sans | Inter | Inter | Inter / Inter |
| hand | Caveat | 文楷字体内的西文字形 | Caveat / Caveat |

为什么正文默认霞鹜、粗标题仍用思源：霞鹜新晰黑、新致宋比思源更有书卷味和辨识度，但**只有常规体**——正文足够（需要加粗的地方引擎自动借用思源的粗体），而照片上的大标题需要 Black 级的分量，只有思源有。霞鹜文楷有 Regular / Medium，用 GB 版（大陆规范字形，教材、学校用更合适）。

### 2.2 单独换某个角色
```yaml
fonts: {preset: hand, title: [caveat, lxgw-marker-gothic, lxgw-wenkai]}   # 标题换成霞鹜漫黑（圆头马克笔风）
fonts: {preset: magazine, body: [source-serif-4, lxgw-neo-zhisong]}       # 正文换成宋体
```
每个角色是一串字体：**西文字体写前面**（只含拉丁字母），中文字体写后面（补中文），再后面的作为缺字备选。

### 2.4 西文字体先按阅读任务搭配

在page-plan.md的整册方案中记下字体分工（家族、字重、大小写/斜体用途），再试排代表性正文页。风格默认值是起点，不能用一个preset名字代替选择理由。

| 文案/视觉角色 | 选择依据与可用组合 |
|---|---|
| 主标题 | 要有主题识别和视觉分量。瑞士方向可用Inter无衬线；文化/摄影编辑方向可试Playfair或Garamond衬线。Display标题字体不因此成为小字号正文首选 |
| 连续正文 | 以实际阅读尺寸的字面、灰度、字宽和段落节奏判断。理性/信息密集可保留Inter；希望增加书刊感可试Source Serif 4；古典文学气质可试EB Garamond，但同px下字面可能显小，需重新试排 |
| 标签与时间/联系方式 | 与正文拉开功能层级，通常用清楚的无衬线；小标签才用适度字距。邮箱/账号保持完整，不因正文换衬线而机械套用花体或全大写 |
| 装饰字、系列号与强调句 | 先定它在页面里的作用，再定字体；可复用标题家族的大数字、标签家族的小眉题，或正文家族斜体的短引语。不为每个角色另加一个新家族 |

通常两家族足以建立层次，第三家族须有明确任务。衬线/非衬线都能做杂志；关键是整册分工及实际排印，不能把“杂志=全衬线”“瑞士=所有角色必须同一无衬线”当硬规则。用户明确要严格瑞士传统时优先无衬线；允许编辑式混排时可保留无衬线标题/导航，正文换衬线，并把方向变化记进brief。

两种方向都应考虑，不能因正文缺少出版气质就只推荐换衬线：
- **衬线标题＋无衬线正文**：让标题建立文化/摄影/时尚气质，正文承担清楚、克制的阅读。可从现有magazine（Playfair标题＋英文Inter正文）试排；标题不必一律Black，Display细节、留白和图片关系共同决定力度。
- **无衬线标题＋衬线正文**：标题建立直接的识别，正文适合需要沉浸阅读的叙述；可用下例，但不是杂志唯一解。
- **同一大类贯穿**：全衬线或全无衬线也成立；用字重、斜体、字面、位置和留白分工，不强求每个角色换家族。短篇、长文、数据页可有不同阅读密度，但仍须保持栏目规则。

参考设计方公开案例：[The New Republic / Pentagram](https://www.pentagram.com/work/the-new-republic)按短篇政治内容与文化长文区分Fakt无衬线正文和Tiempos Text衬线正文；[Cereal / Studio Faculty](https://www.studiofaculty.com/work/cereal-magazine)的一次改版刻意缩小标题与正文的字号差，用留白建立层级。这里借鉴设计决策，不照搬其小字号给学生手册。

例如无衬线标题＋衬线正文，复用已有引擎与字体，不需要新样式系统：
```yaml
book:
  fonts:
    preset: sans
    body: [source-serif-4, lxgw-neo-zhisong, noto-serif-sc]
```

对照先保持相同文案、图片、栏宽与字号，分清字体本身的差异；选定后再按字面大小、行长和密度调字号/行距。长文、密集信息和数字/联系方式至少各查一页，重跑实际PDF；不能靠字号缩小维持页数，不能把字体存在/成功加载当成排版验收。斜体只用于短强调或引语，正文不做全段斜体，长文不加标签式字距。

**四组经典撞色（上表前四行）是内容版式的主力**：效果图 `references/gallery/palettes_overview.jpg`。没写 `book.colors`、风格也没自带配色（photo）时默认 `klein`；第 0 步出方案时先从这四组里推荐。每组有一对撞色 A / B：内容版式里的大色块用它们，A 色块上的字用 B、B 色块上的字用 A；其他方案没写 A / B 时 A = G、B = GOLD。自定义撞色：`colors: {preset: klein, A: '#…', B: '#…'}`（`palettes.py check` 会检查 A/B 之间对比 ≥ 3:1）。

**撞色在印刷手册里怎么落地**：经典撞色的“原色”大多很亮（爱马仕橙、柠檬黄、蒂芙尼蓝），直接做 10px 小字在纸上看不清。所以每套方案都拆成两种用法——原色放在 GOLD（照片/深色底图上的大字、无图风格的大色块与点缀），纸面小字用同色相加深的 G/OCH。比如 `hermes` 的小标签是黑色、斜体强调是深橙，橙色本色出现在深色底图的大标题和瑞士风格的大圆上。
所有方案都过了对比度检查（`python3 hb/palettes.py check`：G/OCH 对纸色 ≥ 5.5:1，GOLD 对 G ≥ 3:1）。

挑方案：先看用途和受众（上表“适合”列），再看风格——深色底图风格（editorial、swiss）配饱和度高的撞色最出效果（klein、hermes、lemon-violet、china-red）；浅色风格（notebook、papercut、aurora）配柔和的（sage、lavender、morandi、tiffany）。拿不准时排两套给用户看，只改一行。

### 3.2 6 个颜色键（自定义 / 品牌色）
| 键 | 用在哪 |
|---|---|
| INK | 纸面正文 |
| G | 纸面上的强调色：小标签、编号、kv 左列、表格行名；也是多数底图的主色 |
| OCH | 纸面上的斜体强调：任务字母、英文副题；浅色底图上的“金色”大字 |
| GOLD | 照片/深色底图上的强调色；底图的点缀色 |
| MUT | 次要文字：页脚、填写栏标签、纸面页眉 |
| PAPER | 纸色（照片和底图都淡出成这个颜色） |

G 和 OCH 是 10–11px 小标签的颜色，要在纸色上有 ≥ 5.5:1 的对比（4.5 是 QA 底线，留出底图透出纸面的余量）——偏亮的品牌色（橙、浅绿、天蓝）通常要加深一档。GOLD 要在深色照片/底图上够亮。
用户给了品牌色：放进 G（太亮就加深一档），品牌色本色或亮色版放进 GOLD；先跑一次看对比度 QA。

|---|---|---|

- `book.gradient` 只用在合适的底上：浅底渐变只上纸面和浅色底图的标题，深底渐变只上照片和深色底图的标题，其他标题保持纯色。写在块里的 `gradient` 不受这个限制。`brand` 两种底都能用。

## 5. 图形语言（所有版式共用）

照片版式（POSTER / T / SPREAD…）和 8 种内容版式现在是同一个引擎（`hb/flow.py` + `hb/canon.py`），图形规则一样：
- **图片位都是矩形，是网格里的一格**：边落在栏线、栏间中线或 28px 行线上；满版就出血到页边。不做斜切、圆形、叶形裁图，不随机放几何。
- **插画只在图片位里**：无图风格的插画（`hb/art.py`，形状词汇见 §1.1 的表）只出现在本该放照片的格子里，不铺到文字下面。
- **装饰默认来自信息本身**：巨型章节号、条目数、关键数字、撞色色块；再加上风格自己的页边装饰（风格派的色格、孟菲斯的拼块、瑞士单色的圆点）。用户指定品牌符号时，可按§7.1延展图形。换风格时换的是字体、配色、插画和页边装饰，网格、字号和撞色节奏不变。

## 6. 字号（A4 印刷）

页面是 794×1123px，对应 A4 的 210×297mm，所以 **1px = 0.75pt**。

**所有版式用同一套网格字号**：A4 默认正文 16px / 行距 28（`book.body: 14` 时 14 / 24，A5、小红书同），其余字号按行距等比，行高都是行距的整数倍或半倍。下表是 16px 网格（括号里是 14px 网格）：

| 用途 | px | 印出来 | 说明 |
|---|---|---|---|
| 封面 / 封底大标题 | 120–160（撑满栏宽） | 90–120pt | 浏览器里量字宽缩放；放不下最小 56 |
| 常规页标题 / 展示型章题 | 常规33、47；展示56–112（按栏宽量字） | 约25、35pt；42–84pt | 标题角色与页面任务先决定档位，不能所有页都用展示大字 |
| 巨型章节号 / 条目数 | 360–600 | — | 装饰，可以压出页边 |
| 关键数字 | 40–160 | 30–120pt | GRID 只有 facts 时 160 |
| 条目 / 卡片标题、引语 | 23–33（20–28） | 17–25pt | |
| 导语 intro | 23（20） | 17pt | |
| 正文 | 16 / 行距 28（14 / 24） | 12pt / 21pt（10.5pt / 18pt） | 中英文默认均16px；这是字号，不等于不同字体的实际字面一样大 |
| 小标签、图注 / 页码 | 标签约13（11）；页码依组件可用正文档 | 约9.6pt（8.3pt） | 当前内容版式页码为16px粗体，不能把整类都理解为同一小字号 |

照片版式的内容块里写的 `size:` 会吸到最近的一档：`title` ≤ 30 → 33px 档、≥ 52 → 展示大字、其余 47px 档；`p` ≥ 18 → 23px 导语档（只在 ≥ 4 栏宽的栏里，窄栏回到正文 16px）；`display` 吸到 23 · 33 · 47 · 56 · 72 · 96 · 120 · 160；`stats` 吸到 47 · 56 · 72。

**行宽与流向**：以layouts.md §0为准；西文按实际字体的约60ch限行，连续长文可分栏，导语和短信息须按语义处理，不固定空出右侧一栏。

**字级表是引擎默认，不是杂志审美处方。** A4的book.body支持14或16，决定布局网格；不能在YAML里假装已有18px正文。默认grid排印的16/28行距比较疏，导语约23/42。西文可选`book.typesetting: editorial`：正文行距为正文的1.5倍，导语为正文1.25倍/行距1.75倍（16px时正文16/24、导语20/28）；块的位置仍吸布局网格，未换一套排版引擎。功能性小标题/编号/信息标签用label家族，页标题用title家族；配合book.fonts选择家族，typesetting本身不强制衬线。默认grid与中文保持原样。

遇到字面小、行距松、导语压过正文、标题全部过重时，把字体、字号、行距、字重、行长和段间距一起试排，不能仅把数字调大或换衬线。超出上述档位的独立行距或正文尺寸仍需修改共用引擎并跑回归，不用单页CSS补丁绕开。

整册方案除字体家族外记录实际字级；代表页在100%成品尺寸或实物试印下判断。先选阅读密度，再建立正文→小标题/导语→页标题→展示字的相对层级；不要求每一级必须用满、不要求所有页标题一律最大。装饰数字可大于主标题，但不能夺走主题识别。自动缩过辅助字的页须回看是否仍清楚；机器的最小字号门禁不是“视觉上已经合适”的证明。

规则：**不要手写小于 11px 的 size**。QA 会把任何小于 10.6px（8pt）的文字报成 `[字太小]`，GATE 判为失败。字号一律由网格决定，一般不写 `size`；想让某一页的字再大一点，换字少的版式或拆页。

### 7.1 可选扩展：品牌图形延展（暗纹与超级图形）

这是现有视觉风格之上的可选品牌语言，适用于需要强化识别的品牌画册、项目手册和系列出版物。用户要求时启用；规划品牌方向时也可将它作为可选方案，依据brief及既有授权取舍。有合适的图形结构才采用，不要求每本册子或每页都有暗纹。正式logo承担识别，衍生图形承担构图、节奏与内容联系。

**先读懂源形。** 查看实际标志，分清用户指定的图形符号、字标和组合标；已有明确指定时直接沿用。保留正式logo原件及品牌规范。优先使用原始矢量；清晰、简单的几何符号可依源图矢量重绘，但须对照比例、轴线、开口、线宽与交织连接，不把近似通用几何当成原标志。重绘资产作为项目衍生图形记录，不冒称官方文件。

**让结构服务内容。** 从源符号的交汇、围合、平行、开口和方向等特征寻找本页构图关系。例如协作内容可呼应交汇，安全/支持可呼应围合，连续进程可呼应同向延伸；这些只是设计者针对本册的解释，不能声称是官方品牌寓意。先在page-plan写“内容任务→源形特征→构图→隐喻”，再决定角度与尺度。

| 应用方式 | 构图方法与作用 |
|---|---|
| 低对比暗纹 | 在阅读纸面上轻显品牌结构，顺应信息布局，保持文字与功能图清楚 |
| 页边一角 | 完整母形等比放大、旋转和移动，借纸边只露转角或交汇处，形态与留白共同构图 |
| 章节锚点 | 放大母形支撑章节转换，与章号、主标题建立主次；阅读页可减弱或留净纸，形成节奏 |
| 跨页超级图形 | 两张真实面对页共用一枚超大完整母形，连接关联内容；先设计合页，再拆为偶数左页与下一奇数右页 |

**保持母形与整册秩序。** 使用完整源路径作等比变换，局部由纸边或前景自然显现；避免页内矩形切口造成标志断裂。相邻/同系列联合考虑，各页取景服务其内容；同册变化应保持同源识别，不靠随机旋转制造差异。允许不使用图形的净页，避免每页同一大小、同一位置反复盖章。

**浓度与保护。** 按纸面、文字密度和实际输出判断暗纹强弱，约5%组透明度可作试排起点，具体数值属于项目决定。浅纸可取品牌色，主题色纸面可取合适的浅/深色；正式logo仍按品牌包规则使用。默认保护原照片、QR/logo与文字，图上应用需有明确构图依据。实际PDF检查主体、可读性和中缝，印刷呈色以打样为准。

**方案与落版交接。** brief记是否启用、指定源形与应用范围；page-plan记录使用页/面对页、源形特征、尺度/角度、内容联系及保护区域，不使用的页无需硬配寓意。源SVG放在本项目photos/_assets/并记录出处，正式logo另保留。共用可选矢量层及参数见blocks.md的brand_graphic；引擎执行已有的变换与保护，源形选择和逐页设计由执行者完成，不自动解读logo。仅写book.brand并不会自动完成本项目的品牌图形方案。后置视觉总监按review.md的H17复核；关闭延展层后原版式应不变。


## 8. 颜色角色与用色档位（`book.color_mode`）
配色按 6 个角色写（借 ppt-master 的角色模型；品牌色锁进对应角色，其余由引擎推出）：
| 角色 | book.colors 里写 | 用在哪 |
|---|---|---|
| 背景 background | `background: '#FFFFFF'` | 纸色，大部分页的底 |
| 次级背景 secondary_bg | `secondary_bg: '#F4F1FF'` | 浅色块（不写 = 背景混 7% 主色） |
| 主色 primary | `primary: '#4B3BFF'` | 标题、大数字；封面 / 章节页的整块 |
| 强调色 accent | `accent: '#C6B8FF'` | 撞色档：第二块整页色；点缀档：深底上的点缀 |
| 次强调色 secondary_accent | `secondary_accent: '#7A2FE0'` | 斜体强调、少量点缀 |
| 正文 body_text | `body_text: '#1A1040'` | 正文、表格 |
旧写法（A / B / G / GOLD / INK / PAPER）照样认。方向样张（directions.py）每个方向旁边都画出这 6 个色卡，用户可以按角色单独改。

用色档位决定这些角色怎么上版面：
- **clash 撞色**：主色、强调色轮流做整页底，A 上的字用 B（只在两色对比 ≥ 4.5 时；不够就用白 / 墨）。适合四组经典撞色（klein、hermes、china-red、lemon-violet）。
- **accent 点缀**：大面积是背景和次级背景；主色整块只给封面、章节页（FULL）；强调色只上数字、细线、小标签；彩色块上只写白字或正文色；有插画 / 照片的封面不盖色块，书名直接压在画面上。品牌色、同色系配色用它。
- **mono 单色**：只用一个主色。`style: swiss` 不写 color_mode 时就是这一档：自动排版默认以白纸和中性浅灰为主，标题、标签用墨色，主色用于编号、大数字、章节号、封面圆点和 `**…**` 包住的字；照片默认转黑白，项目已指定保留原色时用 `duotone: off`。单色指色相数量，不禁止主色整页纸面：显式 `surface: A` 优先于默认节制；不需要为此换成撞色档。其他风格写 mono 时同 accent。
- **auto（默认）**：风格有默认档就用它（swiss → mono）；否则 两色对比 ≥ 3 且色相差 ≥ 45°（或其中一个接近黑白）→ clash；否则 accent。构建时打印判断理由（“用色 accent：同一色系（色相差 7°）…”）。

**无照片页也要规划纸面节奏。** `PAPER`可写`surface: paper / A / B / dark`：依次为纸色、主题色、中性/次级浅底、正文深墨色。它们是实际整页纸面，正文、标签、细线、页眉页脚一起取对应色值；不是给白纸盖一张装饰图。主题色/深墨底按对比度选择白字或黑字，不能主观随便反白；小字需通过4.5:1门禁。无图的费用、报名、服务和封底可用色纸延续全册节奏，不必补无关插图，也不应因为默认mono而全部留白。QR和原logo须另核原图在深底上的完整性与可读性。
四种纸面与无标记清单的控制样张见 `references/gallery/swiss_surfaces.jpg`（虚构文字，无用户素材）。

**用色比例检查**（`colorqa.py`，run.sh 自动跑）：按截图量整本的构成——浅底 / 主色块 / 强调色 / 深色 / 照片插画，参照 60-30-10。
clash 档主色 + 强调色整块超过约 60%、accent 档主色整块超过 20%，或连续 3 页整页色块 → `[颜色过重]`，列出是哪几页（改法：那几页写 `surface: paper`，或换 accent 档）。只提示，不拦截。
没有照片的 photo 风格最容易过重（照片位都变成色块）：照片到了比例自然下来。
