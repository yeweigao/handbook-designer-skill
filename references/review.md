# 审稿尺度

技术验收与视觉结论分开。执行流程和证据格式见 [visual-review](../workflows/visual-review.md)。独立 reviewer 先看 brief 和匿名 PDF，再看作者意图与工程报告；作者自评如实标注。独立基准须先人工校准，其成绩不能由精修样册或重复渲染代替。

| 方面 | 逐页/整册判断 |
|---|---|
| 阅读任务 | 封面与开场能说明给谁看、是什么；各页焦点与次序清楚；行动信息找得到 |
| 内容与语义 | 所有独立信息、数字/单位/条件保留；步骤是真顺序；“本页/右图”等随分页成立；译文含义对应 |
| 排印 | 阅读尺度舒适，正文行长合理；主标题/栏目/序号分工；无孤字、标题孤行、标签和值断开 |
| 密集页与功能 | 名单/表格可查，工作册真能写；无图页有设计，不能靠缩字或无关装饰凑满 |
| 图片 | 真实相关，主体与朝向合理，图注有对应，裁切不误导；跨页坐标连续、中缝不伤主体 |
| 整册与系列 | 字体/颜色/线条自洽，章节转换有意义；系列成员、续页和目录一致，稳定重复可以成立 |
| 最弱页 | 任一关键缺陷须单独修复，不能靠平均分掩盖 |

判定：**不合格** = 有影响阅读、语义、功能或真实性的关键缺陷；**可交付** = 全页完成阅读任务、技术验收有效且必改项关闭；**优秀** = 在可交付基础上，材料特有的视觉主张、照片/排印与整册节奏突出，正文及困难页也成立。

白多、结构重复或没有照片不自动不合格；漂亮封面也不能掩盖正文失败。几何 pass、文字全检出不能证明语义和审美，unverified 不能写 pass。复杂效果若检查器无法确认，明确证据与限制，不以一纸审稿声明绕过硬项。

改动落实到源并看新 PDF；按反馈涉及的共用规则查同类页，保留无关已认可内容及用户本人编辑。不为“更好看”擅改事实或已授权边界。
