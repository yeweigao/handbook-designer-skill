# 图片：用户照片 · 资料里自带的图 · 没有照片 · AI 配图

## 1. 来源与授权
- 用户自己的照片直接用。
- 网上或图库找来的照片：把来源、作者、许可记进 `images.yaml`（run.sh 每次构建自动生成：每张图用在第几页、原图像素、印出来约多少 dpi、是否做了双色调；`source` / `license` / `credit` 三栏由你填，重跑不会覆盖）。导出自检会列出没写来源的图；来源不明的网图不要默认可以用。旧项目的 `image_credits.md` 也还认。
- 构建时还会提示 `[同图两用]`（同一张照片用在两页）、`[低清]`（低于 150dpi），以及 photos/ 里没用上的图（images.yaml 的 `unused`）。
- 用户给的照片明显和内容不符（如幼儿园手册给的是中学生照片）：照用，但在回复里提醒替换。

## 2. 资料里自带图片（宣讲 PPT、带图的 Word/PDF）
`new_project.sh` 会用 `extract.py` 把图片抽到 `photos/`，并给出：
- `doc.md` 里每页的 `<!-- 第 N 页 · 照片：… · 图形：… -->`（图文对应关系，原文核对会忽略注释）
- `images.md`（尺寸、照片还是图形、建议用法）、`photos/_contact.jpg`（缩略图总览）
- 重复出现的 logo / 装饰和小图标放在 `photos/_assets/`

用法：
- 先看缩略图总览，再定页面清单：图跟着它原来那页的文字走。
- **照片**按清晰度用（plan.md 已分好档，阈值只在本节维护）：≥ 2500px 可以满版印刷（FULL、跨页、COLLAGE 大格）；1500–2500px 满版只够电子版，印刷时放进卡片 / 错位 / 组合的图片位或 figure；< 1500px 只做小图。构建时 hb.py 按实际渲染框报 dpi，低于 150dpi 报 `[低清]`。
- **图形**（截图、图表、流程图、插画）只放 `figure`（`fit: contain`，截图加 `frame: true`），不做满版、不放进 COLLAGE、不裁切。
- logo 只用在封面或封底（`logos` 块或 `figure` + `fit: contain`，小尺寸）。
- PPT 的文字多是要点短句：照原样放进 cards / items，不扩写成段落；演讲者备注在 `notes.md`，不是正文，用之前问用户。

## 3. 没有照片
先向用户要（活动现场、学校、产品、往届照片都行）。拿不到时：
1. **无图风格**（`style: editorial / swiss / notebook / inkwash / papercut / riso / aurora / nebula`）：不写图的位置自动生成风格插画，这是正式成品，不是占位。例外：`swiss` 单色档（默认）、`stijl`、`geo` 不生成插画，图片位就是一块安静的色块（不写编号），这几种风格本来就用色块构图；想要插画就换上面其他风格或 swiss 撞色档（`color_mode: clash`）。
   插画只出现在图片位里（网格里的一格或满版），不铺到文字下面；浅色插画上写字时引擎让插画停在文字上方一行。占位示意：`references/gallery/placeholder_example.jpg`。
2. **photo 风格 + 占位**：用户想要摄影杂志风、只是照片晚点给 → `image: placeholder` / `img:` 留空，照片到了填文件名重跑。
3. **AI 配图**（见 §4）。
无论哪条路，都照常用 FULL、COLLAGE、跨页这些图片版式，不要因为没照片就整本排成纯文字页。

## 4. AI 配图
用户素材画风不统一、数量不够、清晰度不够，或用户要求时：以用户素材为锚点，生成一套画风统一的配图。
1. **定美术方向**：从用户素材里挑一个最能代表品牌的做“锚点”，写进项目的 `ai_images.yaml`：`direction`（全书统一的画风说明）、`style`（每条提示词都带的风格后缀）、`negative`（避免项）、`images`（每个图位：`use` 用途、`tone` 明暗、`ref` 参考素材、`prompt` 提示词）。一张图一个主体，图里不放文字、logo、水印。
2. **版式里先占位**：`image: ai:cover`、`img: ai:lab`、`figure: ai:engine`。`run.sh` 会画出带编号和尺寸的占位图，并按实际尺寸和文字落点生成 `image_brief.md`（每个图位：多大、什么比例、文字压在图的哪块、参考哪张素材、完整提示词）。
3. **生成**：有生图工具（任何内置或已接入的都算）就逐个图位调用，存成 `photos/ai_<编号>.png`；没有就把 `image_brief.md` 交给用户，说明怎么在他们的工具里生成、生成后按文件名放回 `photos/`。
4. **重跑看图**：图到了自动替换占位（不用改 yaml）。主体压到文字、画风跑偏的改提示词重生成；明暗和预期相反时给那页写 `tone: light|dark`。
- 不用 AI 重画：品牌吉祥物与 logo、真实的产品界面（必须真截图）、真实的人物和地点。
- AI 图记进 `image_credits.md`（注明 AI 生成）；用户素材里已有的 AI 生成标识不要擅自去掉。
