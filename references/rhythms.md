# 页序起点

这些是内容组织参考，不是强制页数、布局或轮换规律。具体用途见 [用途索引](../purposes/index.md)，整册构图见 [composition](composition.md)。

| 阅读任务 | 可采用的展开 |
|---|---|
| 宣传/招生 | 定位与证据 → 核心项目/体验 → 成果/人物 → 条件与行动 |
| 指南/入学 | 欢迎与找法 → 近期行动/日期 → 地点/人员/规定 → 查阅与紧急联系 |
| 任务册 | 问题与准备 → 单元背景/观察 → 任务与实际书写 → 回顾/展示 |
| 年度回顾 | 年度主题与口径 → 重要故事/数字 → 大事记/名单 → 后续方向 |

短册可合并承接任务，长册增加有效内容与导航。连续阅读和查阅页可稳定重复，呼吸页要有内容理由；不为了每页不同拆散同一时间轴，不为凑页数增写承诺或放无关照片。

页数按内容与约定装订决定：只有 saddle 要求四的倍数，perfect 要偶数，digital/loose 不套骑马钉规则。空白页若确有装订用途应明确记录，不由工具擅自插入。实际左右页、目录和语义关系最终看 PDF。
