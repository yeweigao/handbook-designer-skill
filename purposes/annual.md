# 年度回顾

读者：董事会、家长、合作方、校友——翻一遍记住今年最重要的 3 件事

读完要做的事：认同今年的成绩，愿意继续支持 / 合作 / 捐赠

开场参考：封面一个年度数字或一张年度照片 + 一句年度主题

## 内容任务参考

| 角色 | 阅读任务 |
|---|---|
| cover | 封面 · 年份 + 年度主题 |
| letter | 负责人致辞 |
| numbers | 年度数字 |
| chapter | 章节页（按季度 / 按主题） |
| story | 故事 · 一件事讲透 |
| moments | 照片墙 · 年度瞬间 |
| timeline | 大事记 |
| people | 感谢 / 名单 |
| next | 明年计划 |
| back | 封底 |

可按材料采用、合并或调整，保留重要信息去向，不强制固定页序或构图。

## 审稿重点

- 年度数字都有口径（统计时间、范围）且和原文一致
- 大事记按时间排，日期格式统一
- 名单页：人名逐字核对（错一个字是事故），顺序按原文
- 照片有授权，合影里的人名对得上

内容、规格与授权以项目 brief 为准，自动检查及最终 PDF 审稿见 [契约](../references/contract.md) 与 [review](../references/review.md)。
