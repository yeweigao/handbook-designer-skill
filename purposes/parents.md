# 家长手册

读者：家长（常在手机上看 PDF，也会打印贴冰箱）

读完要做的事：知道要准备什么、什么时候、找谁；按清单做完

开场参考：封面直接说“这本里有你需要的一切”：日期 + 主题

## 内容任务参考

| 角色 | 阅读任务 |
|---|---|
| cover | 封面 |
| letter | 致家长的一封信 |
| calendar | 关键日期 / 日程 |
| checklist | 准备清单 |
| how | 流程说明 · 一步一步 |
| policy | 规定 / 安全 / 健康 |
| contact | 联系人 / 通讯录 |
| faq | 常见问题 |
| chapter | 章节页 |
| back | 封底 |

可按材料采用、合并或调整，保留重要信息去向，不强制固定页序或构图。

## 审稿重点

- 所有日期、时间、电话和原文逐字一致，并按时间顺序排
- 手机竖屏上看得清（正文 ≥ 14px，日期用表格不用大段文字）
- 每条规定都说清“为什么”和“违反了怎么办”（原文有的话）
- 联系人页：姓名、角色、电话、何时打——缺一项就标出来问用户

内容、规格与授权以项目 brief 为准，自动检查及最终 PDF 审稿见 [契约](../references/contract.md) 与 [review](../references/review.md)。
