# 招生简章

读者：正在比较几所学校的家长 / 学生，翻 30 秒决定要不要来开放日

读完要做的事：预约参观 / 扫码报名；在易找的行动区给出原稿已有的流程、截止日期与联系方式

开场参考：封面一句承诺（读者得到什么），不是校名加年份

## 内容任务参考

| 角色 | 阅读任务 |
|---|---|
| cover | 封面 · 一句承诺 + 一张最能代表学校的照片 |
| promise | 开篇 · 校长 / 创始人一段话或一个数字 |
| why | 为什么选我们 · 3–6 个理由 |
| program | 课程 / 项目 · 学什么、怎么学 |
| outcome | 成果 · 升学去向、获奖、数字 |
| campus | 校园与生活 · 照片为主 |
| people | 师资 / 团队 |
| voice | 学生 / 家长的话 |
| fees | 学费 / 奖学金 / 名额 |
| apply | 报名流程 · 步骤 + 截止日期 + 材料 |
| faq | 常见问题 |
| chapter | 章节页 |
| back | 封底 · 联系方式 + 二维码 + 地址 |

可按材料采用、合并或调整，保留重要信息去向，不强制固定页序或构图。

## 审稿重点

- 招生对象、学制 / 年级、费用、截止日期四项，翻到对应页 3 秒内能找到
- 每个“为什么”都有证据（数字、名字、照片），不是形容词
- 数字有口径和年份（“2025 届”“截至 2026 年 3 月”）
- 照片里的学生有授权；没有授权的不露正脸
- 报名页的步骤、日期、联系方式和原文逐字一致

内容、规格与授权以项目 brief 为准，自动检查及最终 PDF 审稿见 [契约](../references/contract.md) 与 [review](../references/review.md)。
