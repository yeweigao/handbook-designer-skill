# 研学任务册

读者：研学途中的学生（边走边看边写），带队老师

读完要做的事：每天完成任务、写下观察；回来交册子 / 做展示

开场参考：封面一张目的地照片 + 一句“这一趟要解决的问题”

## 内容任务参考

| 角色 | 阅读任务 |
|---|---|
| cover | 封面 · 目的地 + 主题问题 |
| welcome | 致同学 / 出发前的话 |
| overview | 行程总览 · 每天一行 |
| rules | 安全守则 / 集合 / 联系人 |
| chapter | 每天的章节页 |
| brief | 当天背景知识 |
| task | 任务页 · 书写区（进阶模式 T / B / PAPER 页 + field / lines / table） |
| reflect | 反思 / 总结 |
| notes | 笔记页 |
| back | 封底 · 紧急联系 + 姓名班级 |

可按材料采用、合并或调整，保留重要信息去向，不强制固定页序或构图。

## 审稿重点

- 每个任务都有足够的书写空间（一行 ≥ 8mm，表格格子能写字）
- 任务说明能在 10 秒内看懂：做什么、在哪做、交什么
- 紧急电话、集合时间地点在封底或第 2 页一眼可见
- 场馆开放时间、门票等事实提醒出发前按官方渠道复核

内容、规格与授权以项目 brief 为准，自动检查及最终 PDF 审稿见 [契约](../references/contract.md) 与 [review](../references/review.md)。
