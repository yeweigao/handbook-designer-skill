# 新生手册

读者：第一周的新生 / 新员工，遇到问题时翻到对应页

读完要做的事：第一周顺利完成报到、找到地方、知道规矩和找谁

开场参考：欢迎与第一周行动清单放在易找的位置，条目数量以原稿为准

## 内容任务参考

| 角色 | 阅读任务 |
|---|---|
| cover | 封面 · 欢迎 |
| welcome | 欢迎辞 |
| first | 第一周要做的事 |
| map | 地图 / 地点 / 交通 |
| people | 找谁 · 部门 / 老师 / 联系方式 |
| rules | 规章 / 守则 |
| life | 生活 · 食堂 / 宿舍 / 社团 |
| calendar | 校历 / 重要日期 |
| faq | 常见问题 |
| chapter | 章节页 |
| back | 封底 · 紧急联系 |

可按材料采用、合并或调整，保留重要信息去向，不强制固定页序或构图。

## 审稿重点

- 目录能直接跳到“找谁”“地图”“规章”（PDF 里目录可点）
- 第一周的事按时间排，每件写清地点和要带的东西
- 规章原文一个字不改；读起来难懂的地方在交付时提给用户，不自己改写
- 地图 / 平面图清晰度够印刷

内容、规格与授权以项目 brief 为准，自动检查及最终 PDF 审稿见 [契约](../references/contract.md) 与 [review](../references/review.md)。
