# 风格锁定（三页小样）

铺全册之前先填这份。它记录的是**决定**，不是装饰：三页定不下来，就不要写第 4 页。
100 页做完再发现风格跑偏，返工的是整本；三页返工，改的是判断。

## 一、这一册的骨架来自哪里

| 项 | 取值 | 出自 |
|---|---|---|
| 家族与版本 | 例：folio 2.2.0 | `project.json.family` |
| 字阶（用到的档位） | 例：112 / 64 / 46 / 32 / 24 / 16 / 13 | `styles[0]`（新册 `folio.css`） 的 `--fl-size-*` |
| 行距与基线 | 例：body 1.75，28px 基线 | `styles[0]`（新册 `folio.css`） |
| 网格 | 例：6 轨 / 12 轨，栏距 6mm | `styles[0]`（新册 `folio.css`） 的 `.fl-grid` |
| 排印模式 | 例：章节扉页 bold、正文 light | `.fl-type-bold / -light` |
| 颜色角色 | 例：纸白 / 墨黑 / 强调 #C83024，软纸 #F2F0EB | `tokens.css`，本册是否改过 |
| 图片处理 | 例：满版出血、3:2 网格内单图、图注在图外 | `references/images.md` |

## 二、必要补丁（没有就写“无，book.css 留空”）

主题与补丁边界见 [style](../references/style.md)。按一项设计需求合并记录，不逐行抄 CSS；共享家族维护不属于本册。

| 阅读任务 | 已尝试的 Folio 组合与具体缺口 | 局部补丁 / 作用域 / 复用 token | 实际 PDF 验证 |
|---|---|---|---|
| | | | |

品牌颜色变更说明角色、原因与对比度。系统级主题变更另记用户要求、基线和新哈希，不能混在局部补丁里。

## 三、三页小样

| 页 | 选它的原因 | 这页要定下来的事 | 结论 |
|---|---|---|---|
| 开场（封面或第一跨页） | 决定读者第一眼看到的语气 | 标题字阶、图片与留白比例、是否出血 | |
| 正文密集页 | 最容易被挤坏的一页 | 行长、栏数、图注位置、行距 | |
| 最难页（表格/图表/长文/跨页） | 最容易崩的一页 | 分组方式、分页、叠放声明 | |

轮次上限 **三**。每轮只改决定，不加装饰；第三轮仍不满意，回去改主张或换骨架，而不是继续堆元素。

## 四、明确不做什么

写下来，防止中途被"更好看"的冲动带跑：

- 例：不加圆角卡片、不用渐变做层级、不给每页顶部加横线。
- 例：不用生成图代替真实素材；没有照片就做纯文字版式。
- 例：不为凑满页面放大装饰字；正文不缩字换容量。

## 五、用户确认

- 确认方式：用户看过哪三页、在哪一轮确认；无人值守时写明"执行者自评"。
- 确认后的改动若触及骨架（字阶、网格、颜色角色），视为重新开小样，重走一次本表。
